## 5. Q&A 대비표
| 예상 질문 | 답의 근거 |
|---|---|
| KTO도 방문자 예측을 하지 않나요? | 시간축 그림(`03` §1-3): KTO는 기존 관광지 상대치, 행안부는 당일 실시간. 우리는 개최 전 행사 단위 절대 인원 + 법정 판정 + 문서 |
| 순간 최대를 어떻게 알죠? | 실측으로 검증한 건 최대 일 방문객이고, 순간 최대는 공개한 가정 산식으로 환산. 가정은 범위로 넣어 구간에 반영. 보도에 순간 인원이 있는 골든 사례로 따로 확인 |
| 과거 데이터로 맞춘 거 아닌가요(누수)? | 공개 시점 규칙(`available_at ≤ D-14`), 학습·보정·평가 연도 분리, 그리고 **미래 행사를 미리 공개 등록한 뒤 채점** |
| LLM이 숫자를 지어내면? | 숫자는 예측 서비스만 만들고, LLM 문장은 자리표시자만 허용 + 숫자 가드. LLM이 꺼져도 예보서는 나온다 |
| 표본이 적지 않나요? | G0 기준·표본 수를 그대로 공개하고, 구간 폭과 "참고용" 표시로 불확실성을 숨기지 않음 |
| 실제로 쓸 수 있나요? | 시범 사용 N건, docx가 한글에서 열림, 로그인·설치 없이 사용, 전국 행사 지도 |
| 확산은? | 전국 행사 일괄 예보(예보 완료 건수), 지자체별 설정 없이 동작, 노트북 한 대로 도는 로컬 설치형 + 오픈소스 공개 가능. 서버 운영은 향후 계획 |
