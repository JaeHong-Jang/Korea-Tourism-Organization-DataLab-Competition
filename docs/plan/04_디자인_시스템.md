# 04. 디자인 시스템 — "살아 있는 미니 대한민국"

> v4 (2026-09-24). 화면 구성은 `03`, 구현 기술은 `05`, 예보팀 구조는 `10`, 근거 그래프는 `09`.
> 색은 dataviz 가이드의 검증된 기준 팔레트를 따르고, 대비·색각 검사는 `validate_palette.js`로 **계산한 값**을 적었다.

## 0. 방향
- **세계관**: 책상 위에 놓인 **미니어처 대한민국**. 블록 인형들이 걸어 다니고, 차와 열차가 오가고, 축제장에는 무대와 천막이 선다. 예보 인원이 많을수록 인형이 모인다.
- **지금 이 순간을 반영한다**: 실제 시각(해 위치)과 실제 날씨(기상청 초단기실황)에 따라 장면과 화면이 낮·노을·밤, 맑음·비·눈으로 바뀐다. 미래 행사를 볼 때는 **그 행사 날 그 시각**의 해 위치와 예보 날씨로 장면을 만든다.
- **화면 틀은 조용하게**: 3D 장면이 주인공이다. 패널·카드·글자는 차분한 편집 디자인으로 장면을 방해하지 않는다.
- **사람이 만든 느낌**: 하나의 세계관(블록 인형·예보팀 펫)으로 일러스트·아이콘·빈 화면까지 통일하고, 템플릿처럼 보이는 요소를 걷어 낸다(§13).

| 현재 날씨 | 기상청 초단기실황(15084084 `getUltraSrtNcst`) — 위경도를 기상청 격자(nx, ny)로 변환 | 헤더 날씨 칩, 3D 비·눈·구름 |
| 행사일 날씨 | 기상청 단기예보(~D+3)·중기예보(~D+10). 그 이후는 "날씨 정보 없음" | 행사장 장면, 재예보 |

**상태 규칙**
| 상태 | 조건(해 고도 h) | 3D 장면 | 화면 테마 |
|---|---|---|---|
| 낮 | h > 6° | 밝은 햇빛, 짧은 그림자 | 라이트 토큰 |
| 노을·새벽 | −6° < h ≤ 6° | 주황빛 낮은 조명, 긴 그림자, 가로등 켜지기 시작 | 라이트 토큰(헤더만 따뜻한 틴트) |
| 밤 | h ≤ −6° | 달빛 + 창문·가로등·무대 조명 발광, 불꽃 행사면 불꽃놀이 | **나이트 토큰** |
| 비·눈 | 강수형태 코드 | 빗줄기·눈 입자, 젖은 바닥 반사, 우산 쓴 인형 | 테마 그대로(글자 가독성 우선) |
- 사용자가 헤더에서 **자동 / 낮 / 밤**을 고를 수 있다(선택은 브라우저에 기억). 발표 때는 "밤·비" 장면을 바로 보여 줄 수 있다.
- 날씨는 **장면에만** 효과를 준다. 글자 위에 빗줄기를 겹치지 않는다.
- 인터넷이 없으면 마지막 날씨 캐시 → 없으면 맑음으로 둔다(해 위치는 항상 계산된다).

## 7. 예보팀 캐릭터(펫)
- **모양**: 참고 이미지처럼 **구름처럼 둥근 몸통 + 어두운 얼굴 창(visor) + 픽셀 눈 두 개 + 가슴 표식**. 우리 캐릭터로 새로 그린다(참고 이미지를 그대로 쓰지 않는다).
- **팀 표시**: 몸통 색 = 팀 색(§3-4), 팀장은 남색 몸통 + 지휘봉. 가슴 표식은 역할 기호: 받아쓰기 `✎`, 동네지기 `⌂`, 기록관 `▤`, 예보관 `∿`, 출처확인 `⌕`, 숫자대조 `#`, 법규담당 `§`, 깐깐이 `?`, 해설가 `“`, 카드장인 `▦`, 계획서 `☰`, 브리핑 `≡`.
- **표정(픽셀 눈)**: 대기(가끔 깜빡임) · 작업(눈이 좌우로, 몸이 살짝 통통) · 완료(눈웃음 ^^) · 보류(눈 − −, 손 들기) · 오류(× ×).
- **형식**: 펫마다 SVG 1개 + 상태 5개(눈·팔 레이어 교체), 움직임은 CSS 키프레임/Motion. 48px(작업판)·32px(로그)·96px(빈 화면·도움말).
- **나오는 곳**: 예보팀 작업판, 작업 로그 줄 앞, 빈 화면·오류 화면, 로딩(펫이 무대를 조립하는 짧은 루프), 도움말.
- **3D 카메오**: 전국 장면 한쪽의 작은 "예보팀 사무실"에 펫 13명이 앉아 있고, 작업 중이면 모니터가 켜진다(P1).

## 9. 3D 미니 대한민국 — 아트 디렉션
- **판**: 한반도 남쪽을 올려 둔 두꺼운 나무판(모서리 둥글게). 판 밖은 배경색. 카메라는 비스듬한 위에서 내려다보고, **틸트시프트(초점 띠 밖 흐림)**로 미니어처 느낌을 준다.
- **땅**: 시군구 폴리곤을 얇게 돌출한 타일. 타일 사이 1px 틈. 데이터 모드에서는 높이·색으로 "기간 내 예보 인파"를 표현.
- **축제장**: 유형별 작은 모형 — 불꽃(발사대), 공연(무대 + 조명탑), 먹거리(천막 줄), 꽃(화단), 대학(무대 + 현수막), 전통(한옥 지붕 천막). 깃발 색 = 등급.
- **블록 인형**: 원통 머리 + 사각 몸통 + 다리 두 개의 단순한 블록 사람(특정 상표 모양을 흉내 내지 않는 자체 디자인). 인스턴싱으로 수천 명. P0는 정적 배치, 걷기(다리 흔들기 + 살짝 통통)는 성능을 잰 뒤 P1. **인형 1개 = N명**(축척마다 범례에 명시), 군중 수는 예보 p50에 비례.
- **차량·열차**: 네모난 장난감 차(도로 위), KTX·지하철(노선 위, 정해진 간격으로 순환). 행사장 뷰에서는 행사 시각에 가까울수록 행사장 방향 흐름이 많아진다.
- **라벨**: 떠 있는 둥근 이름표(행사명 + 등급 아이콘), 줌에 따라 크기 고정.
- **정직한 표시**: 장면 모서리에 항상 "인원 규모는 예보값 비례 · 움직임은 연출"을 적는다. 인형 위치는 실제 사람 위치가 아니다.
- **품질 단계**: 높음(그림자·틸트시프트·반사) / 보통 / 낮음(그림자 끔, 인형 수 1/4). 프레임이 떨어지면 자동으로 낮춘다. `prefers-reduced-motion`이면 인형·차량 정지. 3D를 못 쓰는 환경을 위한 **SVG 전국 지도 + 목록**(P0)과 2D 지도 보기(P1)를 둔다.

## 10. 모션
- 시간: 150ms(호버) · 250ms(패널) · 400ms(카운트업) · 900ms(카메라 이동). 이징 `cubic-bezier(.2,.8,.2,1)`.
- 펫 작업 동작 1.2초 루프, 말풍선은 2.5초 뒤 사라짐.
- 낮↔밤 전환은 2초 동안 조명·하늘을 보간한다.

## 11. 문구·표기
- 짧은 해요체. 팀의 말투로 쓴다: "예보팀이 확인했어요", "동네지기가 인천 중구로 찾았어요".
- 숫자 "2.1만 명"(1만 이상) / "1,450명". 날짜 "10.18(토) 19:00". 확률 정수 %(표본이 적으면 구간).
- 판정 사유: "폭죽 사용 — 법정 기준(인원 무관)", "1,000명 초과 94% — 법정 기준", "5,000명 초과 62% — 자체 기준".
- 면책: "참고용 예보예요. 최종 판단은 담당자가 해 주세요." / 순간 최대 "추정 산식 기반" / 3D "움직임은 연출".

## 12. 접근성·인쇄
- 텍스트 대비 4.5:1 이상, 포커스 링 항상 표시, 키보드로 모든 조작(3D 장면은 행사 목록으로 대체 조작).
- 색만으로 의미를 전달하지 않는다. 차트마다 표 보기, 3D·지도는 카드 목록이 대체 콘텐츠.
- 인쇄: 예보서 A4 한 장, 3D는 정지 화면 1장(현재 카메라)으로 넣는다.
