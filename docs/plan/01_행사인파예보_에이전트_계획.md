## 1. 사용자 시나리오 (에이전트 중심)

**S1. 주최자가 행사를 설명한다**
> "10월 18일 토요일 저녁 7시 영종 씨사이드파크에서 불꽃축제, 인천 중구 주최, 예산 1억, 인스타·유튜브 홍보"

에이전트:
1. 문장 → `{유형: 불꽃, 일시, 장소→시군구 코드(인천 중구), 예산, 홍보채널, 주최 유형}` 구조화. 빠진 값(입장료 유무·회차)은 **되묻는다**.
2. 도구 호출: 유사 행사 검색(같은 유형·시도·예산대·계절) → 3~5건 실적 카드.
3. 도구 호출: 예측 → "예상 12,000~35,000명(중앙 21,000), **1,000명 초과 확률 99%**".
4. 근거 설명: "같은 유형 인천권 3건 평균 1.8만, 토요일 저녁·무료·SNS 홍보는 상향 요인, 개최지 평시 주말 방문 대비 +X배".
5. "안전관리계획 초안 만들까요?" → 행안부 매뉴얼 항목(예상 인원·시간대별 유입·진출입 동선·대피로·안전요원 N·통제 지점·의료·화장실)을 채운 초안 생성 → docx/PDF 다운로드.
6. "개최 7일 전에 재예측해서 알려드릴까요?" → 알림 등록.

**S2. 심사위원 라이브 데모**: 심사위원이 아무 행사나 말한다 → 위 흐름이 30초 안에 스트리밍으로 진행 → 마지막에 "이 모델의 과거 축제 백테스트 MAPE·F1" 패널.

**S3. 백테스트 재현 화면**: "2025 영종 불꽃축제"를 D-14 시점 정보로 넣으면 당시 예상(2,000) vs 모델(만 단위) vs 실제(3만) 비교.

## 3. 에이전트 설계
> 상세(하네스·자동 분석·평가): `02_에이전트_하네스_설계.md`

- LLM: Claude API (tool use, streaming). 시스템 프롬프트에 역할·안전 문구("법적 문서 아님, 참고용") 고정.
- **도구 6개** (FastAPI 엔드포인트를 그대로 도구로 노출):

| 도구 | 입력 | 출력 |
|---|---|---|
| `parse_event` | 자유 문장 | 구조화 JSON + 누락 필드 목록 |
| `geocode_region` | 장소 문자열 | 시도·시군구 코드, 좌표 (TourAPI/행정구역 사전) |
| `find_similar_events` | 유형·시도·예산·월·기간 | 유사 행사 top-k(실적·출처) |
| `predict_attendance` | 구조화 JSON | 중앙값·하한·상한, P(≥1,000), 피처 기여도(SHAP top5) |
| `region_baseline` | 시군구, 날짜 | 평시 일방문자·요일 패턴 (데이터랩 API) |
| `draft_safety_plan` | 예측 결과 + 행사 정보 | 매뉴얼 항목별 초안 텍스트 |
| (선택) `schedule_recheck` | 행사 id, D-n | 알림 등록 |

- 루프: 사용자 발화 → 필요한 도구 호출(병렬 가능) → 근거 문장 생성 → 다음 행동 제안. 도구 호출·결과를 UI에 노출(심사위원이 "데이터랩 어느 데이터를 썼는지" 보게).
- 가드레일: 예측 구간 밖 단정 금지, 데이터 없는 유형은 "유사 사례 부족" 명시, 계획 초안은 "검토 필요" 워터마크.

## 4. 데이터·모델
### 4-1. 라벨(정답) — 두 겹
1. **골드**: 데이터랩 [테마] 문화관광축제 현황 — 지정 축제별 이동통신 방문자(연도별). 로그인 CSV.
2. **실버**: 문체부 지역축제 정보(15143175, 1,214건) 각 축제의 개최지 시군구 × 기간 → 데이터랩 일단위 방문자 API에서 **행사기간 방문자 − 평시 baseline(전후 4주 동요일 평균) = 순증**. 지자체 발표 방문객수는 라벨이 아니라 피처.
3. (검증용) 인천 영종·약사사 등 언론 보도 실제 인원.

### 4-2. 피처
유형(문체부 분류), 기간 일수, 주말·공휴일 포함 일수, 월/계절, 시도, 예산(log), 회차(신규/반복), 입장료 유무, 주최 유형(지자체/민간), 개최지 평시 일방문자·주말 배수(API), 개최지 인구, (선택) TMAP 관광지 검색 전월 순위, 홍보채널 플래그.

### 4-3. 모델
- 회귀: LightGBM on log(방문객) + quantile(10/50/90) → 구간.
- 분류: P(방문객 ≥ 1,000).
- 검증: leave-one-year-out(2019~2025), 유형별 MAPE, F1, 캘리브레이션. baseline = "같은 유형 중앙값", "지자체 예상치".
- 산출물: `models/attendance_lgbm.pkl`, `reports/backtest.md`.
