## 1) 문제점·현안 (데이터랩 수치로 시작)
- ⟦I1: 데이터랩 실측 대비 지자체 발표 방문객 중앙값 X배 — T-206⟧ → 규모 파악 자체가 부정확
- 예상 실패가 곧 안전 문제: 영종(예상 2천 → 실제 3만), 약사사(500 → 1,500) ⟦출처 기사: H8⟧
- ⟦I2: 전국 행사 중 Z%가 1,000명 경계선 — T-206⟧ → 법정 판정이 흔들리는 구간
- 1,000명 미만이라 안전관리계획 대상이 아니어도 차량·보행 동선이 겹치는 사고 위험(안성 사례) → **규모 외 위험 점검**이 필요

## 2) 데이터 활용 방안
- 데이터랩 축제 현황·DIY → 골드 라벨, 일단위 방문자 → 실버 라벨·개최지 평시 기준선
- 문체부 개최계획 10,198건 → 행사 모집단(날짜 원문·개최 달 보존, 부분 일치로 잘못 읽는 일정은 채우지 않음)
- 시행령·매뉴얼 → **4등급 판정**(법정: 1,000명·인원 무관 위험 / 자체: 10%·50%·5,000명) + 규모 외 체크리스트 7종
- **공개 시점 규칙**(예보 기준일 D-14에 공개된 자료만) + 롤링 백테스트로 누수 차단
- 순간 최대 = 일평균 × 피크일 계수 × 동시체류율 — **가정 2개를 범위로 공개**하고 구간에 반영
- 데이터·모델·규정·가정을 온톨로지로 묶은 **근거 그래프**: 모든 AI 설명은 근거에서 나오고, 근거 구조는 SHACL 12개 규칙으로, 숫자·판정 문구는 코드로 검사한 뒤에만 발행
