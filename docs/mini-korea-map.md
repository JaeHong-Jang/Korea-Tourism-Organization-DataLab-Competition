# 미니 대한민국 지도

통합 지도·3D는 `develop_Dongseop`의 `4c48cb5` 버전을 사용한다. 전국 지도에서 행사를 선택하면 해당 동네의 3D 장면을 연다.

## 조작

- 끌기·휠로 지도를 이동·확대한다. 드래그나 확대만으로 행사가 자동 선택되지 않는다.
- 지도 바닥 클릭은 지역 선택과 카메라 이동에만 반영하며 행사 목록 필터는 바꾸지 않는다.
- 행사를 선택한 상태에서는 바닥 클릭으로 선택을 해제하지 않는다. 지도 배경을 더블클릭하거나 전국 보기 버튼으로 돌아간다.
- 동네 행사 이름표의 예보 받기를 누르면 선택한 행사로 상담을 요청한다.
- 화면의 낮·밤 선택을 장면 조명과 하늘에도 반영한다.

## 자료와 표시

전국 지형은 남한 경계에 맞게 자른다. 시군구 경계 파일 `apps/web/public/geo/sigungu.topo.json`은 로컬 공유 자료이므로 새 작업 공간에도 준비해야 한다.

인형 수는 예보에 비례하고 움직임은 연출이다. 실제 행사장 좌표가 없는 경우 시군구 중심 동네임을 표시한다. 예보팀 사무실 이름표는 캔버스 위에 표시한다.
