# 미니 대한민국 지도

성남시 KAIST 공모전의 성남 타임스토리 지도 표현과 조작을 대한민국 범위에 적용했다. 기존 네모 받침판과 지역 선택 시 교체되던 동네 장면 대신, 하나의 정사영 3D 지도에서 전국부터 동네까지 이동한다.

## 조작

- 왼쪽 끌기 또는 한 손가락: 이동.
- 오른쪽·휠 버튼 끌기: 회전.
- 휠: 커서 위치를 기준으로 확대·축소. 두 손가락: 이동·확대.
- 빈 지점 클릭: 현재 각도와 확대를 유지하면서 해당 지점으로 이동.
- 전국 보기 버튼은 왼쪽 안내 카드에 있다. 이동·회전·확대는 마우스·터치·키보드로 한다.
- 지도에 포커스한 상태에서 방향키: 이동. Shift+방향키: 회전. +/-: 확대·축소. Home: 전국 복원.
- 행사 표식 또는 목록 선택: 같은 지도에서 행사 좌표로 확대하고 기존 고래봇 행사 요약과 연결.

## 지도 자료와 표시

OSM/Protomaps 로컬 PMTiles를 사용한다. 시군구 경계는 기존 `public/geo/sigungu.topo.json`이다. 실재 외곽·중정·도로·녹지·수면을 표시하며 임의 건물로 빈 곳을 채우지 않는다. 높이가 있으면 그 값을 쓰고, 없으면 층수×3m 또는 기본 9m로 추정한다. 도로 폭은 분류에 따른 표시 추정이다.

전국은 z7부터 읽고 확대하면 z15까지 읽는다. 화면당 가까운 타일 36개, 파싱 캐시 80개, 동시 요청 4개로 제한한다. 상세 건물 조각 표시 상한은 품질별 7,000/4,000/1,800개다. 모든 전국 건물을 동시에 표시하지 않는다.

이웃 타일의 버퍼 형상은 소유 타일 경계로 자른다. 국토 지표는 실제 국토 마스크로 자르고, 건물은 전체 국토 삼각형으로 위치를 판정하여 해안의 윗면까지 잘리지 않게 한다. 화면 위치 갱신과 타일 요청 키를 분리해 같은 타일 안에서도 표식이 이동한다.

가까운 행사 표식은 묶어서 수를 표시한다. 표식은 대표 행사 좌표에 놓이며 대표 행사 선택으로 확대한다. 모든 행사는 목록에서 선택할 수 있다. `coordSource=centroid`인 좌표는 실제 행사장이 아닌 시군구 대표 위치다.

지면에는 묶음 여부와 관계없이 모든 행사 좌표의 원을 그린다. 원에 마우스를 올리면 행사 이름, 클릭하면 해당 위치 확대를 제공한다. 같은 좌표는 이동시키지 않아 원이 겹칠 수 있으며 전체 목록으로 각각 선택할 수 있다. 원의 크기는 읽기 쉬운 위치 표시일 뿐 실제 행사 경계가 아니다.

현재 화면을 기준으로 보행로·도로의 사람과 차량을 유지하고 선택한 행사에는 기존 부스·무대·관람객 연출을 연결한다. 인형 수는 화면과 품질 상한에 따른 연출이며 예보 인원을 뜻하지 않는다. 철도는 지도 선로를 따르고 항공·해운은 공항·항만 연결 연출이다. 모션 줄이기에서는 움직이지 않는다.

## 자료 공유 범위

`korea-z8.pmtiles`와 `korea-z15-festivals.pmtiles`는 저장소에서 공유된다. 로컬의 전국 `korea-z13.pmtiles`(약 189MB)와 `korea-z15.pmtiles`(약 686MB)는 git 제외 파일이다. 전국 상세 지도 재현에는 별도의 지도 파일 공유가 필요하다. 파일이 없거나 해당 범위가 비어 있으면 지도 상태에 표시한다.

지도 데이터: © OpenStreetMap contributors · Protomaps. 표시는 원본의 등록 범위와 상세 단계에 따라 달라진다.

## 성능

- 타일 읽기·국토 판정·건물/도로/녹지 형상 계산은 작업 스레드(Worker)에서 하고, 완성된 버퍼만 화면에 넘긴다.
- 화면에서 약 2픽셀보다 작은 토지 피복 면·도로는 빼고, 1픽셀보다 촘촘한 꼭짓점은 줄인다(`national-map/area-detail.ts`).
- 실제 고도는 유지하되 시군구의 2.5km 두께 옆면과 바닥을 제거해 행정구역 벽·섬 기둥이 생기지 않게 한다.
- 전국 색면의 고도 분할 간격은 화면 폭/320(60m~8km)이며 확대하면 촘촘하게 복원한다. 산 모양의 기본 지면과 건물 형태는 유지한다.
- 캔버스는 필요할 때만 그린다. 도시 활동은 최대 초당 30번 갱신하고 숨긴 탭·모션 줄이기를 반영한다.
- 최신 측정: 1600×1000 Edge, 전국 이동·회전·확대 8초에서 약 12→60FPS, p95 116.5→17ms, 삼각형 591만→100만. 한 로컬 기기의 측정이며 첫 방문 다운로드 시간·다른 기기 성능을 보장하지 않는다.
- 측정 방법과 결과: `.harness/reports/T-national-surface.md`, `.harness/reports/T-living-city.md`.
