# 2차 리서치 — 여행자 관점 예측·판정형 후보 8건 (에이전트 결과 원문)

## 0. 전제 (경쟁·데이터 팩트)
- KTO가 이미 "관광지 집중률 방문자 추이 예측 정보" API 제공 (관광지 단위, 향후 5주 날짜별 방문 *비율* 예측, 2026-05 갱신) → 단순 "언제 붐비지?"만 하면 중복. 아래 후보들은 이 API를 베이스라인/입력으로 쓰고 시군구 절대수·가격·날씨탄력·세그먼트·대체지로 차별화. https://www.data.go.kr/dataset/15014927/fileData.do
- 20~30대 나들이 부담: 인파 혼잡 37.9%, 교통·주차 20.7%, 물가 18.3% (PMI 1,021명, 2026-04-07) https://www.gosiweek.com/article/1065581523113845
- 국내여행 외면 1위 이유: 높은 관광지 물가 45.1% (한경협·모노리서치, 2025-07-22) https://v.daum.net/v/9pWnmH2XYD
- 소도시 방문 증가 인제 +40.3%·영월 +21.4% (데이터랩 '2027 관광 트렌드 전망', 2026-07-25) https://www.hankyung.com/article/202607244230g

## 후보 1. 시군구 일단위 혼잡 예보 + 대체지 — "토요일 강릉 붐빌까? 대신 어디?"
- 사용자: 20대 국내여행자 20명 A/B
- 예측: 시군구 일 방문자(KT 외지인) D+1~14, 상위10% 혼잡일 이진. 2018~2023 학습/2024~25 검증, MAPE·hit rate·AUC. KTO 집중률 API 베이스라인 대비 개선 %p 보고
- 실체: 지도형 예보 / 목적지→혼잡등급+유사지역 대체지 3곳 / 에이전트 재구성
- 차별: KTO API는 관광지 단위 비율뿐, 대체지·절대수·날씨 없음
- 리스크: 시군구 해상도, 유사도 정의 주관성
- 평가: 창의6/데이터9/성과8/파급7 · 실현성 상

## 후보 2. 산악 시군구 피크주 예보 — "단풍 절정 주말 몇 시에 가야 주차 돼?"
- 근거: 국립공원 탐방객 2025 4,331만(+6.5%) korea.kr; 산림청은 절정일만, 인파 안 줌; 절정 4~5일 늦어져 경험칙 안 맞음
- 사용자: 대학 산악부·등산 동호회 20명
- 예측: 국립공원 소재 시군구 15곳 일 방문자, 연중 피크주 ±3일 hit rate + 크기. 2018~23 학습, 2024·25 시즌 검증
- 실체: 산별 인파 캘린더(절정 vs 인파 분리) / 날짜→혼잡등급·대중교통 / 에이전트 "절정 2주 전, 색 70% 인파 40%"
- 리스크: 시군구≠산, 두 시즌만 검증(15곳×6년으로 보완)
- 평가: 8/8/8/6 · 상

## 후보 3. 시군구 숙박·외식 물가지수 예보 — "이 숙박비 성수기 값이야 바가지야?"
- 근거: 강원 펜션 140만원 논란(2025-08); 물가 45.1%; 정부 바가지 근절대책(2026-02-25)
- 사용자: 커플·자취생 30명(예약 전)
- 예측: 신한카드 시군구×업종(숙박·음식) 외지인 건당 소비단가(월) 1~2개월 예측+계절지수 → 입력 가격 백분위 판정. 2019~24 학습/2025 검증, MAPE·방향 적중률
- 실체: 월별 물가지수 히트맵 / 가격 판정기 / 에이전트 "고성 1.2배, 2주 뒤 1.3배로 하락, 날짜 미루기 vs 지역 바꾸기"
- 차별: 야놀자·여기어때는 개별 매물가만, 기준선 없음. 소비자원은 연1회 PDF
- 리스크: 카드 단가≠1박 요금(비율 지수로만), 월 단위
- 평가: 8/9/7/8 · 상

## 후보 4. 반려동반 가능 × 혼잡 예보
- 근거: 반려가구 45.2% 여행 포기 경험(KB 2025); 지출 3.3배; KTO 2024 반려동반 조사
- 예측: petTour API로 펫 POI 밀도 높은 시군구 일 방문자 D+1~7. 후보1 파이프라인 재사용
- 평가: 8/7/7/8 · 중상

## 후보 5. 지역별 날씨 민감도 판정 + 우천 대안 — "비 오면 이 여행 망하나?"
- 근거: 국내여행 만족 8.3<해외 8.7(날씨 취약); 장마·폭염기 실내 대안 부각(2026-07)
- 사용자: 커플·가족 20팀(비 예보 주말)
- 예측: 시군구별 강수일 방문자 감소율(방문자×기상청 ASOS 2018~) → 우천 탄력도, 특정일 강수 시 감소% + 감소율 30%↑ 취약일 이진. 2018~23 추정/2024~25 검증 MAPE·AUC
- 실체: 목적지→우천 탄력도(해변형 -45%, 도시형 -8%) / 비 예보 결합 "미룰까/갈까" + 우천 둔감 대체 시군구 / 실내 POI 플랜B
- 차별: 날씨앱은 날씨만, 여행앱은 코스만. "이 지역이 비에 얼마나 약한지" 없음
- 평가: 9/8/7/7 · 상

## 후보 6. 검색→방문 선행지표 "뜨는 소도시" 탐지 — "붐비기 전에 가야 해?"
- 근거: 인제 +40.3%; SNS 핫플 해변 인파(2025-06); Z세대 '남들 안 가는 곳'
- 예측: 시군구 월 방문자 다음 달 전년비 증가율 상위 10% 진입 이진+회귀. 입력 TMAP 검색건수·순위, 네비 검색 증가율, 카드 소비 증가율. 2021~24 학습/2025 롤링, precision@10·AUC. 검색→방문 lag 검증
- 실체: 뜨는 중 랭킹(상승/정점/식는 중) / 검색 vs 방문 곡선·예상 정점 월 / 에이전트
- 리스크: TMAP 관광지·월 단위, 케이스 적음
- 평가: 9/9/7/8 · 중상

## 후보 8. 소규모 모임(MT·동아리) 예산 예보 — "가평 vs 강릉, 5월 vs 6월 1인당 얼마?"
- 근거: 대학생 월지출 68.1만, 20대 국내여행 지출 92.5만
- 사용자: 동아리·학생회 총무 5개 모임(실제 지출과 비교 = 실사용 검증)
- 예측: 신한카드 시군구×업종 외지인 20대 1인당 월 소비액 다음 달 예측+계절지수. 2019~24/2025 MAPE
- 실체: 지역·월·인원→1인 예산 범위·항목 비중 / 예산 고정 시 지역 랭킹 / 대안 제안
- 리스크: 결제자 기준(더치페이), 20대 표본 얇음
- 평가: 7/8/8/6 · 상
