## 4. 제약
- KTO API 개발계정 1,000건/일 → 초기 벌크 수집 → 로컬 DB 캐시.
- **시간대(hourly) 데이터: 데이터랩·KTO API 어디에도 없음(확인됨).** 서울 생활인구/실시간 도시데이터 등 일부만.
- **POI 일별 실측 공개 API 없음.** 유일한 POI-일 = 집중률 30일 예측(15128555).
- 공모요강 예시가 로그인 메뉴(지역화폐 소비·유입유출 등)를 들고 있어 **회원가입 후 수동 CSV 확보는 사실상 필수**.
