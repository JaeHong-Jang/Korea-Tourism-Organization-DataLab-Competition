# 2차 리서치 — 역대 학생·소규모팀 수상작의 "실체"와 "성과 증명 방식" (에이전트 결과 요약, 2026-08-18)

## 핵심 결론
- 2025년까지 **서면심사 100%**, 제출물 = 서식4 2~3장 + 참고자료 zip. 웹서비스 구동 심사 없음. **2026부터 상위 9팀 발표심사(8분+7분)** 로 최종 결정.
- 학생/개인 수상팀 성과 증명 수준은 낮음: 자체 설문 288명(KAIST 2024 우수), 회귀·유사사례 추정치(에이블스쿨 2025 우수, 앱은 UX 설계만), 군집분석 시사점 4개(성균관대 2023 우수), 동작 웹데모 화면(DScover 2022 기타부문 대상). 대상·최우수는 항상 실측 성과(외부 출처)를 가진 기관.
- 2025 수상 19건 전체 명단 비공개(대표 5건만).

`/html/interview{,2,3,4,5}/interview01~05.jsp` — Q1 소속·업무 / Q2 문제·현안 / Q3 데이터랩·타데이터 활용 방법 / Q4 성과·기대효과 + 이미지 2~4장.

## 교훈 5
1. 심사 단위는 서식4 2~3장. 데모는 Q3 신뢰도를 올리는 증거이지 자체 점수 아님. '앱·웹 등 서비스 개발' 체크 + 계량성과 칸을 채울 수 있어야.
2. **데이터 활용도 30점은 실측 없이 이길 수 있는 유일한 고배점** — 메뉴명·기간·단위 정확 인용 + 전처리→모델→시사점 단계 구체 서술.
3. 성과 30점은 "추정 + 출처 + 추정임 명시"로 정직하게(에이블스쿨 방식). 소규모 설문(수백 명) 붙이면 "실측 의향".
4. **작지만 실측 가능한 성과 하나**: 배포 후 페이지뷰·이용자 수(요강 예시 "페이지 조회수 3배"), **백테스트 예측 정확도(MAPE)**, 협의 문서. 학생팀 현실 목표 = 우수상, 실측 하나로 차별화.
5. 2026은 발표가 100% — "이 숫자 어디서, 추정 근거는, 누가 쓰나" 산출 과정 부록 준비, 대표자 직접 발표.
