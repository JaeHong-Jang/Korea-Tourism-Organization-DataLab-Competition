### 1-3. 왜 이 문제가 이 대회에 최적인가
1. **데이터랩과 직결**: 언론이 이미 "데이터랩 수치"를 검증 잣대로 인용 → 심사위원(KTO 데이터허브팀)이 만든 데이터의 새 용도.
2. **2026.6.5 데이터랩 개편 기능 정면 활용**: 행사/축제 DIY 맞춤분석에 *비교기간 설정·경제효과 산출*이 신설됨 → "개편 기능을 실전 활용한 사례" 서사.
3. **KTO 공고 기사에서 담당자가 든 예시가 "지역 방문자 특성 분석 → 축제 전략"** → 심사위원 기대 산출물과 일치.
4. **역대 수상작에 축제 성과 검증 사례 없음** (2023 성균관대 통계분석학회는 축제 성공요인 분석 → 우수상; 검증·자동화는 미개척).
5. **파급력**: 1,214개 축제 × 매년 반복. 데이터랩만 있으면 어느 시군구든 즉시 적용.
6. **6주 실현성 최고**: 필요한 데이터가 전부 CSV/API로 즉시 확보 가능, 외부 하드웨어·현장 실증 불필요.

### 1-4. 에이전트가 하는 일 (대시보드와의 차이)
입력: 축제명 (+기간·개최 읍면동은 문체부 축제정보에서 자동 조회)
1. **Baseline 설정** — 전년 동요일 / 직전 4주 평균 중 적합한 기준을 스스로 고르고 축제기간 **순증 방문객·순증 소비**를 계산 (데이터랩 KT 일단위 방문자, 신한카드 지출)
2. **괴리 판정** — 지자체 발표치 대비 괴리 지수 + 원인 가설(수동 계수·중복 계수·행정동 경계·통신 미보유층) 검토·설명문 생성
3. **표준 성과 리포트** — 방문·소비·외지인 비율·성/연령·유입 상위 지역·**예산 1억당 순증 외지인 소비** 를 담은 리포트 자동 생성(PDF)
4. **다음 회차 예측 + 안전 수용력 권고** — 과거 데이터·TMAP 검색 추이로 예상 인파 구간 산출, 1,000명 초과 확률·안전관리계획 초안(행안부 매뉴얼 항목)
5. **비교·랭킹** — 같은 시도 축제 ROI 스코어카드 (인천 28개 축제 등)

→ 1,214개 × 다년도 반복 + 지자체별 집계법 표준화 판단 = 사람 수작업/대시보드로 불가 → 에이전트 필연성.
