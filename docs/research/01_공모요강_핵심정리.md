## 3. 배점표
### 1차 서면심사 (100)
| 항목 | 내용 | 배점 |
|---|---|---|
| 창의성·혁신성 | 접근방식의 독창성과 혁신성 | 20 |
| **데이터 활용도** | 데이터랩 활용도 / 데이터 활용·분석 과정의 구체성·적합성 | **30** |
| **효과성·성과 창출도** | 데이터 활용 결과의 효과성 / 실질적·구체적 성과 창출 정도 | **30** |
| 사회적·경제적 파급력 | 사회문제 해결 기여 or 경제효과 / 가치창출·기대효과 / **타 사례 확산 가능성** | 20 |

### 2차 발표심사 (100)
| 항목 | 배점 |
|---|---|
| **발표 전달력** (핵심 전달력, 질의에 구체적·신뢰성 있는 답변) | **15** (신설) |
| 창의성·혁신성 | 10 |
| 데이터 활용도 | 30 |
| 효과성·성과 창출도 | 25 |
| 사회적·경제적 파급력 | 20 |

**함의**: 데이터활용 30 + 성과 30(25)이 60%. "데이터랩 어느 메뉴의 어느 지표를 어떻게 썼는지"와 "숫자로 된 성과"가 승부처. 창의성은 서면 20 → 발표 10으로 줄고 대신 전달력 15가 생김 → 발표에서는 **라이브 데모 + Q&A 방어**가 중요.

## 5. 서식4 문항 구조 (개조식, **2~3장**, 함초롱바탕 11pt, 줄간격 160)
| 문항 | 요구 | 우리 작성 포인트 |
|---|---|---|
| 응모작 제목 | 예) "방문자 데이터로 개발한 세대별 맞춤 콘텐츠, 방문객 수 200% 신장 이끌다" | **성과 숫자가 들어간 한 문장 제목** |
| 활용 데이터 – 데이터랩(필수) | 메뉴명 나열 | 메뉴명·지표·기간·단위까지 구체적으로 (5종 이상 교차) |
| 활용 데이터 – 타분야(선택) | 예) 사고통계, 설문 | 융합 필연성이 문제 진단에서 도출되게 |
| 성과분야 (1개 체크) | 관광지 안전 / 마케팅·홍보 / 매출·수익 / 전략수립·기획 / 상품·서비스 개발·개선 / **앱·웹 등 서비스 개발** | 1개만. 서사와 일치시킬 것 |
| 핵심성과 (1~2줄) | 데이터 융합 → 성과 | 숫자 2개 이상 |
| 계량성과 | 예) 방문객 +50%, 체류 +2h, 조회수 3배 | 실측 KPI + 추정 KPI + 채택신호 3층 |
| 1) 문제점·현안 | 수치 3개 내외 | **데이터랩 수치로 시작** |
| 2) 데이터 활용 방안 | 데이터랩 (+타분야) 활용 | 탭 교차분석 과정 |
| 3) 사업 개선·적용 사례 (구체적으로) | 시범사업 등 | 웹서비스+에이전트 실제 운영 |
| 4) 추진성과·기대효과 (정량 위주) | 전후 비교 %·절대치 | 시범운영 실측 + 추정 + 확산 조건 |

## 6. 규정 리스크
- **타 공모전 채택 사례 또는 기본 구상이 매우 유사하면 심사 제외** → 이 대회 하나에 집중.
