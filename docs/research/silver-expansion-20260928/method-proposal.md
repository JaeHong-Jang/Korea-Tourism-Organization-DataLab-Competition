# 실버 1,804건 활용을 위한 예측·검증 설계안

작성일: 2026-09-28. 이 문서는 학습 전 합의한 설계안이다. 승인 후 첫 연구 실행을 완료했으며 실제 결과는 [results.md](results.md)에 기록했다. 서비스에는 적용하지 않았다.

사용자 요청 범위: 현재 후보를 최소한으로 전처리해 활용하는 방법을 정하고 연구 근거를 남긴다. 웹페이지·운영 모델·원본 데이터 변경은 이번 작업에 포함하지 않는다.

## 1. 제안하는 결정

**1,804개 실버 행사 행을 보존하고, 부호가 있는 ‘행사 기간 시군구 방문 순증’을 예측하는 별도 실험을 먼저 한다.** SNR·음수·명절에 따른 일괄 삭제를 해제한다. 같은 지역·기간의 중복 관측을 보정하고, 시간순 검증으로 채택 여부를 판단한다.

첫 후보는 동일 관측 가중치의 얕은 LightGBM 분위수 모델이다. 중앙값과 하한·상한을 함께 예측한다. 0 순증·유형 중앙값 기준선과 비교하고, Huber 회귀는 단순한 대안으로 둔다. 논문이 특정한 SNR 가중치나 이 데이터의 성능 개선을 보장하는 것은 아니다.

이 실험이 예측하는 값은 **시군구 방문 변화량**이다. 행사장 방문객·순간 최대 인원으로 쓰려면 별도의 연결 근거가 필요하다. 순증 예측을 기존 순간 최대 환산에 바로 넣지 않는다.

근거 목록: [논문·실무 문헌과 적용 범위](sources.md). 집계 재현 도구: [audit.py](audit.py).

## 3. 무엇을 예측할 것인가

현재 실버 라벨 산식은 다음과 같다.

```text
B(r,w) = 행사 시작 전 28일 중 공휴일을 제외한 같은 요일 방문객의 중앙값
delta_i = mean_d [지역 방문객(r_i,d) - B(r_i, weekday(d))]
현재 SNR_i = delta_i / 평시 요일별 잔차의 표본 표준편차
```

초기 실험의 타깃은 `regional_increment_daily = delta_i`, 단위는 명/일, 공간 범위는 시군구다. 값이 -5,000이면 선택한 기준선보다 해당 기간 시군구 방문이 하루 평균 5,000 적었다는 뜻이다. 행사 참석자가 음수이거나 0명이었다는 뜻이 아니다.

현재 σ는 일별 잔차의 표준편차이며 행사기간 평균 차이의 표준오차가 아니다. `SNR>3`은 코드의 휴리스틱 품질 조건으로, 통계적 유의성이나 신뢰수준을 보장하지 않는다. 강한 관측 결과만 남길 때의 크기 과장 위험을 다룬 Gelman·Carlin 연구[R1]를 이 설계에 참고하되 검정식이 동일하다고 주장하지 않는다.

시군구 변화에는 다른 행사·관광·통근·날씨·계절 영향이 함께 섞인다. `B`를 ‘축제가 전혀 없던 상태’로 확정할 수 없다. 초기 모델의 결과 이름은 관측 기반 순증 예측으로 한정한다. 행사별 인과효과 추정은 통제 시계열과 가정 검증을 갖춘 후속 과제다[R4].

## 4. 최소 전처리 규칙

| 항목 | 기본 처리 | 이유 |
|---|---|---|
| SNR 낮음 | 삭제·추가 감점 없이 보존, 진단 열만 유지 | 결과가 작은 행사를 학습에서 없애지 않기 위함 |
| 음수·0 순증 | 원값 유지, 절댓값·0 치환 금지 | 부호가 있는 관측 변화량이기 때문 |
| 설날·추석 | 포함, 달력 피처와 별도 성능표 | 피처 추가만으로 명절 교란이 해결된다고 가정하지 않음 |
| 극단 순증 | 자동 상하위 절단 없이 원자료 확인, 강건 손실 사용 | 큰 실제 행사일 가능성을 보존 |
| 동일 event_id의 다른 라벨 | 실버 타깃은 실버 1행, 골드는 별도 평가 자료로 보존 | 공간 범위가 다른 정답을 섞지 않음 |
| 같은 시군구·동일 기간 | k개 행사 행은 유지하되 각 행 학습 가중치 1/k | 동일 관측이 여러 번 학습되는 것을 보정 |
| 일부 겹친 기간 | 겹침 군집 표시, 경계 분할 방지, 군집별 성능 진단 | 행사별 효과를 분리해 관측한 것으로 오해하지 않음 |
| 일정·지역 연결 오류, 비유한 수치, 데이터 단절 | 원인 기록 후 해당 행 격리 | 계산 불가능한 값만 제외 |
| 피처 결측 | 결측 표시 및 학습 구간 안에서만 대체 | 결측만으로 행 전체를 버리지 않음 |

1/k는 SNR 신뢰도 가중치가 아니라 반복 관측의 총 영향력을 1로 맞추는 규칙이다. 동일 기간의 행사별 피처가 다르더라도 같은 지역 결과를 관측한 것이므로, 행사별 귀속 효과를 주장하지 않는다. 나중에 지역·기간 단위로 묶어 행사 수·유형 구성을 입력하는 대안과 비교할 수 있다.

코드상 숫자 0·음수/명절 제외를 해제하려면 기존 스키마도 바뀐다. 초기 실험은 기존 labels.parquet의 플래그를 덮어쓰지 않고 별도 연구 데이터셋으로 만든다. 골든 평가 전용으로 지정된 행이 생기면 모든 실험의 학습·튜닝에서 계속 제외한다.

추가 진단: 전체 날짜 확정 행사 목록과 비교하면 277개 후보가 다른 행사와 기간이 겹치고, 602개 후보는 시작 전 28일 달력 구간에 다른 행사가 있다. 이는 **달력상 겹침** 집계로, 실제 기준선에 사용한 같은 요일·비공휴일 표본의 오염을 확정한 수가 아니다. 공개일이 검증되지 않은 행사 목록으로 과거 예측 피처를 만들지 않는다.

## 5. 초기 모델과 가중치

최소 실험 순서:

1. 순증 0 예측: 모든 행사에 지역 변화 없음으로 예측하는 기준선.
2. 학습자료 유형별 중앙값: 해당 유형 표본이 20행 미만이면 전체 중앙값으로 대체. 20은 프로젝트의 사전 고정 실험값이다.
3. LightGBM 분위수 회귀: α=0.1·0.5·0.9, 원래 부호가 있는 delta를 직접 학습. p50은 중앙값이며 평균이라고 부르지 않는다.
4. 필요 시 Huber 회귀 비교: 큰 잔차의 영향을 완화하되 표본을 삭제하지 않는 단순 모델[R2].

LightGBM은 L1/quantile 목적함수를 제공한다[R6]. 초기 파라미터 후보는 `num_leaves={7,15}`, `min_child_samples={20,40}`, `learning_rate=0.05`, `n_estimators=200`, `seed=2026`. 나머지는 설치 버전 기본값을 저장한다. 이 수치는 문헌의 추천 임계값이 아니라 복잡도를 제한한 프로젝트 실험값이다. 작은 4개 조합만 2024 개발 구간으로 선택하고 2025·2026 평가 전 고정한다. 상수 피처와 고유 event_id·행사명 문자열은 입력에서 제외한다.

현재 `log1p(delta)`와 `max(0,prediction)`은 새 실험에서 사용하지 않는다. 음수를 손실 없이 처리한다. 분포가 매우 치우치면 부호 보존 변환은 후속 민감도 실험으로만 추가한다.

**기본 가중치는 관측 구간당 동일하게 둔다.** 현재 σ를 곧바로 라벨 오차분산으로 보고 1/σ²를 주지 않는다. NIST는 추정 가중치가 적은 반복 측정에 의존하면 불안정할 수 있음을 설명한다[R3]. BIV 연구는 라벨별 잡음분산 추정치를 확보한 조건에서 가중회귀를 다룬다[R5]. 현재 σ에는 실제 지역 변동도 포함되어 그 조건을 충족했다고 보기 어렵다.

신뢰도 가중치는 후속 후보로만 둔다. 행사 결과와 무관한 사전 관측 누락률·기준선의 시간순 예측오차 등에서 측정 신뢰도를 추정하고, 학습자료에서 정한 상하한으로 제한한다. 결과 크기를 포함한 SNR·잔차 부호로 가중치를 정하지 않는다. 가중치를 적용할 경우 `(sum w)^2 / sum(w^2)`와 구간 수를 함께 보고하며 이를 시간상 독립 표본 수라고 부르지 않는다.

## 6. 기준선과 피처

첫 실험에서는 기존 28일 동일요일 중앙값 라벨을 유지해 **표본 선택 변경의 효과**부터 확인한다. 기준선을 동시에 바꾸면 어떤 변경이 성능에 영향을 줬는지 구분하기 어렵다.

다음 단계에서만 28일 대 56일 기준선, 명절·계절·추세 통제, 다른 행사 기간 마스킹을 별도 비교한다. 행사 없는 것으로 확인 가능한 가짜 행사 구간에서도 순증이 과하게 생기는지 검사한다. 비교 지역을 쓰는 CausalImpact는 통제 지역의 비영향·관계 안정성 가정을 점검한 뒤 적용한다[R4].

입력 피처의 초기 목록:
- 행사 요청에서 주어지는 유형·기간·월·주말 및 법정공휴일 일수·명절 여부·요금·주최·회차.
- 공개 시점을 통과한 지역 평시 방문객·외지인 비중·요일 패턴·관측일 수·자료 경과일.
- 예산은 과거에 요청 입력으로 주어졌다는 가정이 가능할 때만 포함하고, 공개 근거가 없으면 제외한 민감도 결과도 보고.
- 전회차 실버 순증은 해당 라벨이 D-14에 공개됐을 때만 후속 실험에 포함. 골드 전회차 인원은 의미가 다른 별도 열.

해당 행사의 SNR·행사기간 실제 방문·사후 순증·실제 날씨·사후 발표 인원은 예측 피처에 넣지 않는다. 명절 등 사전에 알 수 있는 정보와 사후에야 아는 품질 진단을 분리한다.

공개 지연 주의: 현재 지역 관측은 35일 지연, 예측은 D-14다. `region_features.py`의 `[as_of-56, as_of)` 창과 공개일 조건을 함께 적용하면 대략 D-70~D-49의 22개 날짜만 남는다. ‘D-14 직전 8주를 모두 본다’고 표현하면 잘못이다. 후속 실험에서 최신 공개 관측일까지의 56일로 창을 옮기는 방안을 별도 비교한다.

학습용 정답 계산에 행사 후 실제 관측을 사용하는 것은 필요하다. 그 정답이 나중에 공개된다는 사실을 지키고, 해당 행사 예측 입력으로 새어 들어가지 않게 해야 한다. 과거 API 개정 이력과 행사 속성의 당시 공개본이 없는 한 완전한 시점 복원이라고 주장하지 않는다.

## 7. 시간순 학습·보정·평가

연도 전체를 보정에 떼어 놓는 현행 분할 대신, **과거 자료를 늘려 가는 월별 평가**를 기본 후보로 둔다[R7].

1. 평가 월의 첫날−14일을 모델 학습 마감일 T로 고정한다. 모델은 그 달 동안 고정한다.
2. `label.available_at ≤ T`인 과거 라벨만 학습·보정 후보로 쓴다. 월중 결과를 앞선 예측으로 소급해 넣지 않는다.
3. 개별 행사 피처는 해당 행사의 실제 D-14 기준으로 생성한다. 평가 월 전체의 실제 방문 관측을 피처에 넣지 않는다.
4. 시간순 정렬된 과거 겹침 군집 중 최근 20%를 올림하여 보정 전용으로 예약하되 최소 50개 군집으로 한다. 해당 군집 행은 전부 함께 이동한다. 군집 최대 공개일·최대 종료일·event_id 순으로 정렬하고 서로 다른 분할의 실제 행사기간 겹침을 재검사한다. 군집 일부가 아직 공개되지 않았다면 그 군집의 과거 행도 해당 시점에서는 제외한다.
5. 남은 학습이 100개 군집 미만이면 이 실험의 구간 보정 결과는 미제공으로 표시하고 단순 기준선만 보고한다. 20%·50·100은 문헌상 보장값이 아닌 사전 고정 운용 초안이다.
6. 동일 지역·동일 기간의 행은 반드시 같은 분할에 둔다. 평가 대상은 시작일이 해당 월인 행사로 고정하고, 평가 행과 겹침 군집을 공유하는 과거 행은 학습·보정에서 제외한 뒤 그 수를 남긴다. 다른 월 행사를 해당 월 평가로 당겨오거나 중복 채점하지 않는다.
7. 2024년 월별 결과로 소수 후보를 선택하고, 2025는 과거 비교, 2026은 고정한 후보의 추가 검증으로 보고한다. 기존에 살펴본 2025·2026 자료를 완전히 미열람한 최종 시험이라고 부르지 않는다. 향후 행사 예보를 사전 저장한 진짜 전향 검증을 별도로 남긴다.

실제로 계산한 연초 후보 풀(실버만, 구간 보정용 분리·경계 검사 전):

| 평가 연도 | 연초 학습 마감일 | 공개된 과거 행사 행 | 고유 지역·기간 | 해당 연도 평가 후보 |
|---|---|---:|---:|---:|
| 2024 | 2023-12-18 | 372 | 366 | 439 |
| 2025 | 2024-12-18 | 786 | 773 | 635 |
| 2026 | 2025-12-18 | 1,418 | 1,392 | 358 |

표의 786·1,418을 모두 순수 학습 수라고 부르지 않는다. 실제 학습·보정·제외 수는 월별로 분리해 출력한다. 현행 52건은 2025 평가용으로 2023년까지의 엄격 필터 표본만 학습하고 2024년을 보정에 사용한 결과다. 필터와 분할을 각각 개선하면 이 제한을 줄일 수 있다.

### 7.1. 후속 질문에 따른 실제 분할 건수

`split_counts.py`로 위 규칙을 적용한 결과다. 아직 피처 생성·모델 학습을 수행하지 않았으므로 확정 학습 실적이 아닌 분할 후보 수다. 보정은 군집 수의 20%이므로 행사 행 수가 정확히 80:20이 되지는 않는다.

| 평가 연도 | 연초 첫 모델 학습 | 연초 구간 보정 | 연초 군집 경계 제외 | 해당 연도 전체 평가 후보 | 평가가 있는 월의 학습 수 범위 |
|---|---:|---:|---:|---:|---:|
| 2024 | 294 | 78 | 0 | 439 | 294~584 |
| 2025 | 624 | 162 | 0 | 635 | 624~1,041 |
| 2026 | 1,135 | 282 | 1 | 358 | 1,135~1,355 |

2026년 전체 358건은 현재 스냅샷의 1~8월 행사다. 첫 1월 모델은 7건을 평가하고 이후 매월 과거 자료로 재학습하므로, 1,135건으로 고정한 모델 하나가 358건 전부를 평가하는 구조가 아니다. 2026년 연초 기준 1,804행의 구성은 학습 1,135 + 보정 282 + 2026년 평가 후보 358 + 공개 지연으로 아직 못 쓰는 이전 연도 28 + 군집 경계 제외 1이다. 이 제외는 원본 삭제가 아니며 이후 월에 조건을 충족하면 사용할 수 있다. 이미 평가한 행도 정답 공개 후 다음 월 학습·보정 후보에 들어갈 수 있고, 과거 예측은 다시 계산하지 않는다.

세부 월별 수치의 재현 코드는 [split_counts.py](split_counts.py)에 저장했다.

동일 축제의 전년도 사례를 쓰는 것은 실제 재예보에 맞는 조건이다. 다만 신규 축제에 대한 일반화는 별도 진단한다. 연도 간 행사 이름·지역을 검토해 동일 시리즈를 연결하고 기존 축제/신규 축제의 성능을 나눠 보고한다.

## 8. 무엇으로 개선을 판단할 것인가

주 지표는 **지역·기간별 동일 총 가중치를 적용한 MAE(명/일)**, 보조는 중앙 절대오차·RMSE·평균 오차(과대/과소 방향)다. 음수와 0 근처 값이 있는 새 타깃에는 MAPE/MdAPE를 주 지표로 쓰지 않는다[R8].

분위수는 pinball loss, p10~p90 실제 포함률, 평균/중앙 구간 폭으로 평가한다. 구간 보정은 CQR[R11]을 참고한 원단위 보정으로 고정하고, 학습에서 예약한 보정 자료만 사용한다. 평가 자료를 보정에 재사용하지 않는다.

구체적으로 세 분위수 예측을 오름차순 정렬해 교차를 해소한 뒤, 보정 행별 점수는 `s_i = max(p10_i - y_i, y_i - p90_i, 0)`으로 계산한다. 동일 지역·기간에 k행이 있으면 보정에서도 각 행에 1/k를 주고, 정렬된 점수의 누적 가중치가 전체의 80% 이상이 되는 첫 값을 c로 정한다. 최종 구간은 `[p10-c, p90+c]`다. 0 하한은 구간을 축소하지 않는 프로젝트 선택이며, 원 논문의 보정 규칙·유한 표본 보장과 동일하다고 주장하지 않는다. 중복 보정과 시계열 의존성을 포함한 이 설계의 실제 포함률·폭은 월별 평가로 확인한다[R9].

중복 1/k로 학습한 모델의 채점은 각 행의 손실을 구간 안에서 평균한 후 구간별로 평균한다. 원래 행사 행 기준의 무가중 성적도 함께 보고한다. 전체 행사에 대한 오차와 관측 구간별 오차가 무엇인지 구분한다.

필수 결과표:
- 전체 유효 평가 후보, 기존 SNR>3 교집합, 저SNR, 양수/음수, 명절/비명절, 겹침/비겹침, 연도·유형별 N과 MAE.
- 기존 ‘학습에 사용 가능’ 표본의 교집합 성적은 회귀 타깃과 관측 기간을 맞춰 비교. 골드가 섞인 기존 86건의 종합 MdAPE와 새 signed 전체 MAE를 직접 비교하지 않는다.
- 0/유형 중앙값/새 모델을 동일한 평가 구간에서 비교한다. 기존 모델 출력은 의미가 혼합된 참고값으로만 표시한다.
- 실험 분해: 같은 시간 분할에서 SNR>3 학습 대 전체 signed 학습을 비교하고, 동일 후보에서 현행 연도 분할 대 새 월별 분할을 추가 비교한다.

모델 채택은 먼저 2024 개발 결과에서 기준선보다 MAE·pinball loss가 낮은 후보를 고르고 단순성도 고려한다. 성능 개선 최소 %를 결과를 본 뒤 만들지 않는다. 2025·2026에서 재현되는지, 음수·저신호 오차나 큰 양수의 과소예측이 급격히 악화되는지 함께 보고 최종 결정한다. 지역을 묶어 오차 차이를 재표집하는 보조 구간과 월별 분산을 보고하며 명절 36건처럼 작은 부분집합에는 과도한 결론을 피한다.

## 9. 행사 인원 예측과 연결하는 조건

이 설계로 자료를 늘려도 행사장 일평균 방문객이나 순간 최대의 정답이 늘어나는 것은 아니다. 입장객과 지역 순증은 배경 유동·중복 방문·주민 이동 때문에 일대일로 대응하지 않는다. 행사장·시간대·통신 셀을 정의하고 실제 인원과 대조한 참석자 추정 연구가 이 구분을 뒷받침한다[R10].

후속 인원 모델에 필요한 자료는 동일 행사·기간의 행사장 집계와 시군구 순증의 쌍이다. 골드A/B·계수기·입장권 등의 출처와 공간·시간·중복 집계 정의를 맞추고, 다양한 유형·규모·지역에서 수집한다. 작은 행사와 큰 행사 둘 다 포함한다. 목표 확보 수는 수집 계획으로 정하되 특정 수를 넘으면 검증 완료라고 보장하지 않는다.

쌍이 충분해진 후 지역 순증 예측을 보조 피처로 사용하는 행사장 인원 모델을 검토한다. 이때도 학습 행의 순증 예측은 시간순 학습 밖 예측값으로 만들고, 행사장 실제 인원 평가셋으로 검증한다. 단순히 순증의 음수를 0으로 바꾸거나 일정 배수를 곱해 참석자 수로 명명하지 않는다.

순간 최대는 시간대 실측이 없으면 체류·운영시간 가정에 의존한다. 일간 순증 모델의 정확도가 개선됐다고 순간 최대·혼잡 등급까지 검증됐다고 결론 내리지 않는다.
