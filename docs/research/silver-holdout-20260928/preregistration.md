# 고정 분할(2023~24 학습 · 2025.1~8 검증 · 2025.9~2026.8 테스트) 사전 등록

작성: 2026-09-28, 실행 전. 요청자 지정 분할로 다시 판정한다. 이 문서의 SHA-256을 실행 산출물에 기록하고, 결과를 본 뒤 내용을 바꾸지 않는다.

## 1. 공개해 둘 한계

- 검증·테스트 기간(2025~2026)의 성적은 v1·v2 실행에서 **이미 열람했다.** 이 분할의 테스트는 독립 시험이 아니다.
- 분할 방식 자체를 그 열람 뒤에 정했다. 결과는 월별 재학습 방식(v1·v2)과 나란히 참고로 보고한다.

## 2. 분할

| 구간 | 범위 | 행 수 |
|---|---|---:|
| 학습 후보 | 2023~2024 시작 행사 중 정답 공개일 ≤ 2024-12-18 | 811 − 25 = 786 이하 |
| 검증 | 2025-01-01 ~ 2025-08-31 시작 | 364 |
| 테스트 | 2025-09-01 ~ 2026-08-31 시작 | 629 |

- 기준일 2024-12-18 = 검증 첫날(2025-01-01)의 D-14. 이 날 뒤에 공개된 2024년 정답 25행은 학습에 넣지 않는다.
- 공개가 일부만 끝난 군집과 검증·테스트 행과 같은 군집은 학습에서 뺀다(v1 규칙과 같다).
- 학습 후보의 최근 20% 군집(최소 50)은 예측구간 보정 전용이다. 나머지가 학습셋이다.
- **모델은 한 번만 학습한다.** 검증과 테스트 모두 같은 모델로 예측하고, 매달 다시 학습하지 않는다.
- 입력 피처의 D-14 공개 제약, 중복 가중치, LightGBM 설정(트리 200, 학습률 0.05, seed 2026)은 v1·v2와 같다.

## 3. 후보와 선택

변형 4개(`base`=v1 입력, `prior`, `relative`, `prior_relative`) × 파라미터 4개(잎 7·15 × 최소 잎 표본 20·40) = 16개.
검증셋 가중 MAE 오름차순 → pinball → 잎 수 적은 쪽 → 최소 잎 표본 큰 쪽 → 변형 순서로 첫 번째를 고른다. 테스트셋은 선택에 쓰지 않는다.
기준선: 순증 0, 유형별 중앙값(학습셋 기준), SNR>3 학습 대조군(같은 보정·평가 행).

## 4. 판정 기준 (모두 충족해야 운영 승격 후보)

`v1 월별`은 이미 저장된 v1 월별 재학습 예측을 같은 테스트 행으로 잘라 비교한다.

| 번호 | 조건 |
|---|---|
| H1 | 검증: 선택 설정의 MAE와 pinball이 모두 유형별 중앙값보다 낮다 |
| H2 | 테스트: MAE가 유형별 중앙값과 v1 월별보다 낮다 |
| H3 | 테스트 큰 양수 순증(2023 가중 90% 분위수 25,692.5 이상): 포함률 50% 이상, MAE가 v1 월별보다 낮다 |
| H4 | 테스트 명절: MAE가 v1 월별보다 높지 않다 |
| H5 | 테스트 전체 구간 포함률 75% 이상 90% 이하 |
