# 데이터 신청·다운로드 안내

> 2026-09-24 링크 확인. 받은 파일은 아래 "저장 위치"에 두면 파이프라인이 읽는다(`data/`는 git에 올라가지 않는다).
> 키·비밀번호는 `.env`에만 적고 채팅·커밋에 붙이지 않는다.

## 1. 공공데이터포털(data.go.kr) — API 키 (H1)
1. https://www.data.go.kr 로그인(회원가입 필요 시 가입).
2. 아래 링크마다 **[활용신청]** → 활용 목적 "2026 한국관광 데이터랩 활용 경진대회 서비스 개발" → 신청. 개발계정은 **자동승인**이다.
3. 마이페이지 → 인증키 발급현황에서 **일반 인증키(Decoding)**를 복사해 `.env`의 `DATA_GO_KR_KEY=`에 넣는다. 한 키로 아래 API를 모두 쓴다(승인 직후 몇 분~1시간 동안은 호출이 안 될 수 있다).
