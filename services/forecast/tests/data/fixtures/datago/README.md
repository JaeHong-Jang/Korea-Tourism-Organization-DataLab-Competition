# T-101 방문자 녹화 응답

`visitors_20250901_20250907_page_*.json`은 T-101에서 승인받은 실호출 6건의 응답이다.
인증키와 요청 URL은 저장하지 않았다. `fetched_at`은 실제 UTC 수집 시점이고,
`payload`는 JSON 응답 원문이다. 요청은 `startYmd=20250901`, `endYmd=20250907`,
`numOfRows=1000`, `pageNo=1..6`이다. 총 5,544행·264개 시군구·부모 시 12개다.

출처: [한국관광공사 지역별 방문자수 공식 명세](https://www.data.go.kr/data/15101972/openapi.do).
응답의 소수 방문자 수와 2025년 행정구역 코드를 그대로 보존했다.
파일 전체 SHA-256이 `source_hash`다.

`crosswalk_20260701_page_1.json`은 오케스트레이터가 벌크 수집한
`20260701~20260731` 첫 페이지의 기존 캐시를 그대로 복사한 녹화본이다.
이 수정에서 추가 호출하지 않았으며 광주·전남 27개 코드, 화성 부모·구,
인천 개편 코드를 모두 포함한 7월 1일을 변환 회귀 검사에 사용한다.
SHA-256: `3859d98c55f16a08ef7546eb1fbb64fe08d3311860205dda23e6b32ce76cc4fa`.
6월 30일 경계와 8월 25일까지의 부분 응답 테스트는 이 녹화본·기존 녹화본의 날짜 변형이다.

`empty_20260826_20260831.json`은 게이트 수정 중 미수집 구간을 확인한 실제 응답이다.
`totalCount=0`, `numOfRows=0`, `items=""`인 정상 무자료 응답을 담고 있다.
형식 오류로 잘못 판정했던 응답을 재현하려고 한 번 더 호출해 녹화했으며,
최초 확인 1건과 녹화 1건을 모두 공유 호출 장부에 기록했다.

특일·집중률·TourAPI 테스트의 소형 응답 및 과거 날짜 경계 사례는
공식 명세와 이 녹화본을 기반으로 만든 변형이며 별도 실호출 녹화본은 아니다.
