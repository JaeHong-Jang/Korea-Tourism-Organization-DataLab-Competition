# 기상청 날씨 파싱 픽스처

출처는 공공데이터포털의 [단기예보 활용가이드](https://www.data.go.kr/data/15084084/openapi.do)
(2026년 7월 첨부, DOCX 파일명 260623)와
[중기예보 활용가이드](https://www.data.go.kr/data/15059468/openapi.do)
(2025년 12월 첨부, DOCX 파일명 241128)다. 2026-09-25 확인했다.

`*_sample.json`은 공식 문서의 응답 XML 예제를 JSON 형태로 고정한 파일이다.
실 API를 호출해 녹화한 자료는 아니다. 항목 값은 문서대로 보존했고,
문서에서 생략된 행 때문에 페이지 검증에 실패하지 않도록 `totalCount`를 실제 예제 행 수로,
`numOfRows`를 1000으로, `dataType`을 JSON으로 맞췄다.
요청 URL과 인증키는 포함하지 않는다. 나머지 테스트는 이 항목들을 변형한 경계 사례와
서울 종로의 합성 회귀 응답을 사용한다. 실호출 검증은 T-105 지시대로 오케스트레이터가 수행한다.

격자 기대값은 같은 단기 가이드의 `격자_위경도(2607).xlsx`에서
종로구·해운대구·수원시팔달구·제주시의 위경도와 격자를 가져왔다.
`(37.488201, 126.929810) → (59, 125)`는 가이드 LCC 예제다.

`WeatherClient`는 `ultra_now(nx, ny, at)`, `short_term(nx, ny, base)`,
`mid_term(region_code, base)`를 제공한다. 시간대 없는 시각은 KST로 해석한다.
`at`은 조회 시점이며 초단기실황 제공 지연 10분을 반영해 회차를 선택한다.
`base`는 정확한 발표시각이다(단기 02·05·08·11·14·17·20·23시, 중기 06·18시).

결과의 `records`는 KST `valid_at`별 정규화 dict다. 기온은 ℃, 강수확률은 %, 풍속은 m/s다.
미제공·결측은 `null`이고, 단기 연장 구간의 풍속 코드는 `wind_speed_category`로 분리한다.
중기 광역 코드(`11B00000`: 수도권)는 하늘·강수, 도시 코드(`11B10101`: 서울)는
일 최저·최고기온을 조회한다. 함께 필요하면 두 코드를 각각 호출해 날짜 기준으로 사용한다.
광역 코드에 특정 도시 기온을 임의로 붙이거나 중기 기온을 시간별 값으로 바꾸지 않는다.

각 행의 `evidence`에는 인증키 없는 출처 URL, 캐시 SHA-256, 발표·수집 시각이 들어간다.
`available_at`은 수집 시각보다 앞서지 않는 보수적 가용 시각이므로 과거 발표 자료를
오늘 처음 수집해도 학습용 과거 시점에 소급할 수 없다. 예보는 `estimated: true`다.
기본 캐시는 `CROWDCAST_DATA_ROOT/data/cache/weather/`, 기본 호출 장부는
T-101과 동일한 `data/cache/datago/ledger.csv`다. 캐시 디렉터리를 바꿔도 기본 장부는 바뀌지 않는다.
