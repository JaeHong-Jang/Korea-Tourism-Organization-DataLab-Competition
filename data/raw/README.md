# 📁 원본 데이터 (Raw Data)

이 디렉토리에는 원본 데이터가 저장됩니다.
**Git에 포함되지 않으므로**, 아래 안내에 따라 직접 다운로드해주세요.

## 팀 공유 자료로 한 번에 받기 (권장)
팀 구글 드라이브의 `crowdcast-data-20260926-v2.zip`(98MB)을 받아 **레포 루트에 풀면** `data/`·`models/`·`reports/`(backtest·runs·evals)가 채워진다.
- 들어 있는 것: 연도별 문화관광축제 목록, 데이터랩 다운로드(정답 라벨), 시군구 경계·행정안전부 인구, 가공 자료(`processed/`), 공공데이터 API 캐시, 앱 저장소(행사 기록 DB·근거 그래프), 학습된 모델, 백테스트 결과(`reports/backtest/` — 없으면 새 예보가 503 '사용 모델 포인터가 없습니다'), 실행 기록·평가 보고서
- 들어 있지 않은 것: API 키(`.env`), 지도 타일(저장소 `apps/web/public/tiles/`에 이미 있음)
- 데이터랩·공공데이터 자료라 팀 안에서만 쓰고 외부에 다시 올리지 않는다.
