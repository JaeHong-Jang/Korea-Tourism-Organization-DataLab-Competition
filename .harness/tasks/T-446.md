  - **봇 = 사용자 고래 그림**: `whale-mark.png`를 `public/assistant/whale.png`로 복사해 쓴다(3D 캔버스 제거 — 가볍게). 살짝 떠다니는 CSS 움직임·눈 깜빡임 대신 상태 표시(대기·작업 중 — 예보팀이 일할 때 흔들림과 작은 점 세 개·발행 완료 — 체크), reduced-motion이면 정지. **포인터로 끌어서 옮기기**(화면 안으로 제한, 위치 기억 — try/catch), 키보드로도 옮기기(Alt+방향키), 끌다 놓은 것과 누른 것 구분.
  - **말풍선**: 처음 방문엔 "행사를 고르거나 물어보세요" 한 줄 + [사용법 +] — 누르면 화면별 **사용법 단계 안내**(성남 타미처럼 해당 요소를 강조하며 3~5단계: 지도·목록·예보 받기·대화·근거 그래프), 닫으면 다시 안 뜸(기억).
  - **대화는 사람 말로**: 발행 문장을 근거 칩과 함께 줄줄이 늘어놓지 않는다 — 결과는 **요약 카드 하나**(행사명·등급 아이콘 + 글자·순간 최대 구간·한 줄 결론 — 숫자는 forecast 카드 값 그대로) + 게이트웨이 `reply`(팀장 말) + [예보서 보기] [근거 보기(근거 그래프·근거 지도)] [계획 초안]. 체크리스트·권고 문장은 "준비할 것 N가지" 접힘으로(펼치면 문장만, 칩 없음). 근거 칩·근거 서랍은 예보서(S3)와 근거 그래프에서만.
  - **AI가 일하는 게 보이게**: 요청 뒤 대화에 **실시간 작업 줄**(현재 일하는 팀원 펫 얼굴 + 이름 + `agent_status.note` — "동네지기가 개최 지역 평시 방문을 확인하고 있어요…", 차례로 바뀜, 끝나면 "예보팀 12명이 확인했어요 · 게이트 통과" 한 줄로 접힘 — 펼치면 단계 목록), 입력 중 표시. 가짜 지연·가짜 단계는 만들지 않는다(스트림 이벤트 그대로).
  - **위치**: 대화 입력 옆 [내 위치로 가까운 축제] — 브라우저 위치 허락 시 메시지에 `near {lat,lng}`(저장 안 함), 거절이면 "지역 이름을 말해 주세요".
  - **작업판**: 팀장 한 줄(가운데) → 분석팀 한 줄 → 검증팀 한 줄 → 보고팀 한 줄(팀 이름표 왼쪽), 카드 크기 통일, **예보서 미리보기와 같은 높이**(넓은 화면 두 칸 격자에서 행 높이 맞춤).
