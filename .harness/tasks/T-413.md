- 인터페이스:
  - **데이터 = 스냅샷 하나**(`GET /api/forecasts/{id}` — knowledge를 따로 부르지 않는다, 9/25 결정). 노드: 문장(발행 claim, `layout` 순) → 근거(evidence, kind별 모양·아이콘 + 글자) → 출처(데이터셋 id·규칙 id·조항·모델 버전·가정 id) → 데이터셋/문서(master-labels 이름 + 데이터랩 메뉴 경로). 같은 출처는 한 노드로 합친다(여러 문장이 같은 근거를 쓰는 게 보이게).
  - **배치**: elkjs layered 왼→오(문장 → 근거 → 출처 → 데이터셋), 노드 수가 많아도(~150) 겹치지 않게, 처음 화면에 전체 맞춤. 배치 계산은 한 번(메모), 창 크기 변화엔 fitView만.
  - **상호작용**: 노드 클릭/Enter → 근거 노드면 서랍 카드 열기(칩 번호 = 예보서 번호, 닫으면 출발 노드로 포커스 복귀), 문장 노드면 해당 문장 강조 + "예보서에서 보기", 데이터셋 노드면 원문 링크(새 탭). 노드 hover/포커스 → 연결된 경로만 강조. 근거 종류 필터 칩 6개, 요약 줄("발행 문장 N개 · 근거 M개 · 데이터랩까지 이어지는 문장 K개").
  - **접근성·대체**: 키보드로 노드 순회, [표로 보기](문장 · 근거 · 출처 · 데이터셋 표 — 같은 자료), `prefers-reduced-motion`이면 애니메이션 없음, 인쇄 때 탭 숨김.
