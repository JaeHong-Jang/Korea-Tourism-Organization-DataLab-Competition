# T-306c: 세션 없이 예보서에서 계획 초안 만들기 — `POST /api/forecasts/{id}/plan`
- 레인/워커: L3 / gpt-6-astra        - 선행: T-306 완료(계획서 에이전트 — develop 76596bc)
- 목표(한 문장): 예보서 화면(S3, `/f/:id`)은 상담 세션 밖이라 "계획 초안 만들어 줘"를 보낼 수 없다 — 계획서 담당은 records 스냅샷만 있으면 되므로, 게이트웨이에 **예보 id로 같은 규칙의 계획 초안을 만들고(이미 있으면 그대로) 계획과 docx 경로를 돌려주는** 경로를 연다.
- 읽을 것: services/gateway/src/team/{lead/followup-plan.ts, report/{plan-writer,plan-templates}.ts}, services/gateway/src/routes/{plans,forecasts}.ts, services/gateway/src/clients/records-client.ts, packages/contracts/{schemas/plan.schema.json, openapi/{gateway,records}.yaml}, `.harness/tasks/T-306.md`(끝의 결정 — 새 문장 없이 스냅샷 발행 문장 배치), AGENTS.md §3·§5
- 허용 경로: `services/gateway/src/routes/`(`plans.ts` 또는 `forecasts.ts`에 한 경로), `services/gateway/src/team/lead/followup-plan.ts`(세션 없이 부를 수 있게 배치·저장 부분을 함수로 떼는 최소 수정), `services/gateway/tests/`, `packages/contracts/openapi/gateway.yaml`은 **건드리지 않는다**(오케스트레이터가 반영 — 리포트에 CONTRACT-CHANGE로 경로·요청·응답을 적는다)
- 인터페이스: `POST /api/forecasts/{forecastId}/plan`(본문 없음) → records `GET /v1/snapshots/{forecastId}`(없으면 404 `{"error":"not_found"}`) → T-306과 **같은 함수**로 섹션 배치·계획 id(`plan-<forecastId에서 f- 뺀 값>`)·저장(409 → 기존 조회) → 200 `{plan: <계약 plan>, docxHref: "/api/plans/{id}/export.docx"}`. 새 문장·게이트·SSE 없음. records 422 → 502 `{"error":"plan_rejected"}`.
- 수용 기준(실행 명령): `npm -w services/gateway test`·`build`·`lint`, `node scripts/dev.mjs --check --only gateway`. 새 테스트: 스냅샷 있음 → 계획 생성·같은 요청 두 번 = 같은 계획, 스냅샷 없음 → 404, records 422 → 502, 세션 경로(T-306 follow-up)와 **같은 계획**(같은 예보면 두 경로 결과가 바이트 같음).
