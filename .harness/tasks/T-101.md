# T-101: data.go.kr 클라이언트(방문자·집중률·TourAPI·특일) + 캐시·호출 장부·공개 시점 + 벌크 수집 CLI
- 레인/워커: L1 / gpt-6-astra        - 선행: T-100 완료, H1(키 확인됨)
- 목표(한 문장): 일 1,000건 한도를 지키며 방문자 API를 2018년부터 벌크 수집하고, 모든 행에 공개 시점(available_at)을 붙여 Parquet으로 쌓는다.
- 읽을 것: docs/plan/06 §1(9/24 확인한 데이터 사실 — 2025 코드 체계, **부모 시 코드 12개 이중 계산 주의**)·§3(공개 시점 규칙), docs/reference/데이터_신청_안내.md, AGENTS.md §3 규칙 6(호출 한도)
- 허용 경로: `services/forecast/src/crowdcast/data/{datago_client.py,visitors.py,concentration.py,tourapi.py,holidays.py,call_ledger.py}`, `services/forecast/tests/data/`(녹화 응답 픽스처 포함)
- 인터페이스:
  - `datago_client`: serviceKey(`.env`의 `DATA_GO_KR_KEY`, 로그 금지)·MobileOS·MobileApp·`_type=json`, 페이지 순회, 재시도(tenacity), 응답 캐시(`data/cache/datago/<api>/<요청 해시>.json`), **호출 장부**(`data/cache/datago/ledger.csv`: 날짜·API·호출 수 — 하루 900건을 넘기면 멈춘다)
  - `visitors`: `locgoRegnVisitrDDList`(numOfRows 1000) → `data/processed/region_daily.parquet` 열 `sigungu_code, sigungu_name, date, tou_div(현지인|외지인|외국인), visitors, is_parent_city(bool), available_at(= date + 4일), source_hash`. **부모 시 코드(41110 등 12개)는 is_parent_city=True로 표시**하고 합계에 쓰지 않는다
  - CLI: `uv run --package crowdcast-forecast python -m crowdcast.data.visitors --from 2018-01-01 --to 2025-12-31 --max-calls 800`(중단·재시작 가능, 이미 받은 구간은 건너뜀)
  - `concentration`(15128555)·`tourapi`(searchFestival2·searchKeyword2)·`holidays`(특일): 클라이언트 함수만(호출은 필요할 때)
- 수용 기준(실행 명령):
  - `uv run --package crowdcast-forecast pytest -q services/forecast/tests/data` 통과(녹화 응답으로 페이지 순회·캐시 적중·장부 한도·부모 시 표시·available_at 계산)
  - 실호출: `--from 2025-09-01 --to 2025-09-07` 실행 → region_daily 행 수와 시군구 수(264, 부모 12 표시) 리포트에 기록, 장부의 호출 수
- 범위 밖: 전체 기간 벌크 실행(오케스트레이터가 한도를 보며 나눠 실행), 라벨 계산
- 외부 호출: data.go.kr ≤ 30건(테스트용), 패키지 설치
- 코드 규칙: AGENTS.md §5
