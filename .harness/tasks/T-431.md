# T-431: 3D 미니 대한민국 기반 — 캔버스·투영·시군구 타일·카메라·해 조명(낮·노을·밤)·품질 3단계·성능 측정

- 목표(한 문장): React Three Fiber로 한반도 남쪽 시군구를 얇게 돌출한 "나무판 위 미니어처 땅"을 그리고, 실제 해 위치로 낮·노을·밤 조명을 바꾸며, LLM 추론과 GPU를 나눠 쓰는 상황에서 프레임 시간을 잰다.

- 인터페이스:
  - 의존성: `three`·`@react-three/fiber`·`@react-three/drei`·`d3-geo`·`topojson-client`(루트에서 `npm install -w apps/web …` — 그 명령이 바꾸는 루트 `package-lock.json`만 허용). 후처리(`postprocessing`)는 이 task에서 쓰지 않는다(P1, T-435)
  - 투영: d3-geo 횡메르카토르(한반도 중심) → 장면 좌표 1단위 = 1km. 시군구 폴리곤을 얇게 돌출(ExtrudeGeometry), **시도 단위로 형상 병합**(그리기 호출 수 ↓), 면 인덱스 → 시군구 코드 표로 클릭 판정(`onPick(sigunguCode)`) — 선택은 T-401의 `selection-store`에 넣는다
  - 판·색: 모서리 둥근 두꺼운 나무판, 땅은 04 §3-6의 크림·연녹 4~5색을 지역마다 번갈아(데이터 의미 없음), 바다 청록 무광. **색은 토큰(`design-tokens.css`의 3D 변수)에서 읽는다 — 하드코딩 0**. 토큰에 3D 색이 없으면 리포트 `CONTRACT-CHANGE:`로 요청하고 임시로 가장 가까운 기존 토큰을 쓴다
  - 조명: T-401 테마 엔진의 해 상태(낮·노을·밤)와 `suncalc` 방위·고도 → DirectionalLight 방향·세기, 상태별 HemisphereLight·배경색. `?theme=`·`?at=` 강제 쿼리를 그대로 따른다(스크린샷 재현)
  - 카메라: 비스듬한 위(기울기 고정 범위), 드래그 회전·휠 확대 한도, 키보드(화살표·+/-) 이동, 선택한 시군구로 부드럽게 이동
  - 품질 3단계 `high|medium|low`: drei `PerformanceMonitor`로 프레임이 떨어지면 자동으로 낮춤, `AdaptiveDpr`, 탭이 숨으면 렌더 중지. `prefers-reduced-motion`이면 카메라 자동 이동 없음
  - 정직한 표시: 장면 모서리에 항상 "인원 규모는 예보값 비례 · 움직임은 연출"(`honest-note.tsx`, T-402가 이 문구 위치를 모바일에서 옮긴다 — 겹치지 않게)
  - 대체: WebGL2가 없으면 캔버스 대신 "3D를 쓸 수 없는 환경이에요 — 목록으로 보기" 안내(SVG 대체 지도는 T-404)
