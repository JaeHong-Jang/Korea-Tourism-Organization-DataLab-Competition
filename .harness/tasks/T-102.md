# T-102: 행사 마스터 — 시군구 코드 매핑·행정구역 사전·geocode 후보·TourAPI 일정 보강

- 인터페이스:
  - `admin_dict`: 2025 체계 시도·시군구 사전(코드·정식 이름·줄임 이름·옛 이름 — 예 "강원도"→"강원특별자치도", "인천 중구", 부모 시 "수원시"→41110). 경계 252개 + 방문자 API 264개(부모 시 12개 포함)를 합친다
  - `events`: `python -m crowdcast.data.events` → `events.parquet` 열 = 06 §10 `events`(event_id, name, year, edition, type, start, end, time_of_day, sido, sigungu_code, venue, lat, lng, budget_krw, fee, host_type, hazard_flags, source, is_golden) + `date_text`, `planned_month`, `sigungu_match`(exact|alias|parent|venue|ambiguous|none), `coord_source`(tourapi|centroid|none), `continuity_break`(06 §1 인천 개편 지역이면 true), `visitors_announced`·`visitors_announced_meaning`(라벨 아님 — 06 §2 단위 메타데이터 그대로)
    - `event_id` = `e-<year>-<sigungu_code 또는 00000>-<sha1(정규화 이름+시군구+연도) 앞 10자리>`(계약 패턴 통과, 같은 입력 = 같은 id). 같은 행사가 두 번 나오면(같은 해·시군구·정규화 이름) 한 행으로 합치고 출처를 목록으로
    - 시군구가 시 단위(구 있는 부모 시)면 부모 코드 그대로(`sigungu_match=parent`) — 방문자 API가 부모 시 합계를 준다
    - `hazard_flags`: 이름·장소·유형에서 계약 hazard enum(폭죽·불·수면·산 …)을 규칙으로(키워드 표는 코드 상수, 확실할 때만)
    - `is_golden`: 골든 목록 파일이 없으면 전부 false(H8 뒤 채운다 — 파일 경로 인자로)
  - `geocode.candidates(venue_text, sido_hint=None) -> list[{sigunguCode, sigunguName, lat, lng, score}]`: 행정구역 사전 + (있으면) TourAPI 좌표로 후보, 모호하면 여러 개(예 "중구"는 시도 없으면 6개). T-204의 `/v1/geocode`가 그대로 쓴다
  - `festival_dates`: TourAPI `searchFestival2`로 **2026-09-29~2026-11-30 시작** 축제를 받아(캐시·장부 — T-101 클라이언트, 호출 30건 이하) 문체부 2026 행과 이름·시군구로 맞춰 날짜·좌표를 채운다. 맞는 문체부 행이 없으면 `source=TourAPI` 행으로 추가. 맞춤 규칙·점수를 QC에
  - 좌표: TourAPI 좌표가 있으면 그것(점-다각형으로 시군구 일치 확인, DuckDB spatial 또는 shapely), 없으면 시군구 경계 중심점(`coord_source=centroid`)
