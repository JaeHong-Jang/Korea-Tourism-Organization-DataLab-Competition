# T-436: 3D 성능·접근성 — 자동 품질 단계·저사양 프리셋(30fps)·reduced-motion 점검, 장면 설명(스크린 리더), 장면 캡처(PNG 저장)

- 읽을 것: docs/plan/04 §9(품질 단계·**프레임 합격선** — 자동 측정은 같은 실행 기준 대비 p95 ≤ 1.3배)·§12(접근성)·§10, docs/plan/11 M1-F1·M3-F4, apps/web/src/components/scene/(quality·scene-diagnostics(`performance.regress`)·effects·weather·motion·venue), scripts/perf/scene-frame-time.mjs(조건 `--t433`·`--t434`·`--t435`), `reports/figures/perf/`(이전 측정), AGENTS.md §3·§5
- 허용 경로: `apps/web/src/components/scene/`, `apps/web/src/features/venue-3d/`, `apps/web/src/styles/`(장면 부분), `scripts/perf/scene-frame-time.mjs`, `tests/e2e/`(`scene.spec.ts`·`s3-venue.spec.ts` 보강)
- 할 것:
  1. **자동 품질**: 프레임이 계속 느리면 한 단계씩 내린다(높음 → 보통 → 낮음 — 후처리·입자·그림자·인형 수 순서로 끔), 빨라지면 한 번만 올린다(깜빡임 방지 — 히스테리시스). 사용자가 고른 품질은 존중(자동 끄기 선택지). **저사양 프리셋**(`?sceneQuality=low` 또는 하드웨어 동시성 ≤ 4·기기 메모리 ≤ 4GB 추정): 후처리·입자 끔, 인형 1/4, 그림자 끔 — 목표 30fps.
  2. **매 프레임 할당 0 점검**: 날씨 입자·걷기·불꽃·차량 루프에서 `new`·배열 생성·클로저 생성 제거(행렬·벡터 재사용), 언마운트 때 geometry·material·texture·렌더 타깃(후처리) 해제 — 탭 전환 10회 뒤 `renderer.info.memory` 증가 없음(e2e 진단).
  3. **reduced-motion**: 입자·걷기·불꽃·차량·열차·봇·카메라 이동 모두 정지(정지 화면 유지) 재점검.
  4. **장면 설명**: 캔버스 옆 시각적으로 숨긴 요약(`aria-live="polite"` — 선택·필터가 바뀔 때만): "전국 판 · 표시 행사 N건 · 등급 4 대규모 N건 … · 선택: 행사명(등급, 순간 최대 p10~p90명)" / 디오라마: "행사장 반경 1.2km · 건물 N동 · 시각 HH:MM · 날씨 …".
  5. **장면 캡처**: 장면 모서리 [장면 저장] → 현재 캔버스(후처리 포함)를 PNG로 내려받기(`preserveDrawingBuffer` 없이 — 요청 프레임에서 한 번 읽기), 파일 이름 `crowdcast-<화면>-<YYYYMMDD-HHmm>.png`, 정직한 표시 문구를 이미지 아래 띠로 함께 그린다.
- 수용 기준: `npm -w apps/web test`(품질 히스테리시스·저사양 판정·장면 설명 문구·캡처 파일 이름)·build·lint·색 하드코딩 0, e2e(자동 품질 강등 → 후처리 꺼짐·DPR 낮아짐, 탭 전환 10회 메모리, 장면 저장 → 다운로드 이벤트·PNG 크기 > 0), 성능 `--t436`(같은 실행 T-433b 기준 대비 **높음 p95 ≤ 1.3배**, 저사양 프리셋 p95 기록). 실행은 오케스트레이터.
