# 미니 대한민국 도구 패널 삭제와 지도 최적화

- 사용자 요청: 스크린샷의 지도 도구 패널을 삭제하고 지도 렉을 개선한다.
- 허용 경로: apps/web/src/components/scene 및 해당 검사, features/mini-korea, pages/mini-korea-page.tsx, docs/mini-korea-map.md, 본 task/report, reports/runs/mini-korea-map 실행 산출물.
- 예보·검증·기록 숫자와 API, 계약, 의존성, 다른 페이지는 수정하지 않는다.
- 스크린샷 도구 패널과 불필요한 상태 연결을 제거한다. 기존 포인터·터치·키보드 지도 조작을 유지한다.
- 실제 타일 파싱과 상세 형상 생성의 메인 스레드 병목을 측정하고 개선한다. 이동 중 과도한 요청·형상 생성과 정지 화면의 반복 그리기를 줄인다.
- 수용 기준: 지도 단위 검사와 빌드·변경 파일 lint, Chromium에서 패널 제거·지도 조작·행사 선택·지도 실제 형상·요청 취소 검증, 동일 조건 최적화 전후 측정 기록.
- 파일/블록 한 줄 한국어 주석, 파일별 300줄 이내. Git 읽기 전용. 외부 API 호출 없음.
