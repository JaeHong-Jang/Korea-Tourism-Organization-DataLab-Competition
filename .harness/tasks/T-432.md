- 인터페이스:
  - 입력은 prop `festivals: FestivalSummary[]`(계약 타입). 이번 task는 **견본 목록**으로 그린다: `?sceneFixture=1`일 때만 계약 픽스처 모양의 견본 30건(유형 6종·등급 1~4 섞음, 전국 흩어짐 — `components/scene/__fixtures__/festivals.ts`, 이름은 "견본 행사 n"처럼 실제 행사로 오인되지 않게). 쿼리가 없으면 빈 목록(모형·인형 없음) — 실제 API 연결은 T-433
  - **모형**(04 §9): 불꽃(발사대)·공연(무대 + 조명탑)·먹거리(천막 줄)·꽃(화단)·대학(무대 + 현수막)·전통(한옥 지붕 천막), `기타`는 작은 광장 천막. 저폴리 기본 형상 조합(외부 모델 파일·텍스처 없음), 재료 색은 `--scene-model-*`. 위치 = 행사 좌표(투영), 크기는 판 축척에 맞게(행사장 모형 폭 ≈ 3~4km 상당 — 겹치면 약간 밀어낸다, 결정적으로)
  - **깃발**: 모형마다 깃대 + 깃발(색 = `--level-N`) — 색만으로 구분하지 않도록 **이름표에 등급 아이콘 + 글자**(04 §3)
  - **이름표**: 떠 있는 둥근 이름표(행사명 + 등급 아이콘·글자), 줌과 관계없이 화면 크기 고정, 가까운 이름표끼리 겹치면 등급 높은 쪽 우선 표시. 키보드·스크린리더용으로 장면 밖에 같은 내용의 목록이 있다(`aria` — T-433 목록과 합쳐질 자리)
  - **블록 인형**(04 §9): 원통 머리(`--scene-doll-head`) + 사각 몸통 + 다리 두 개 — **자체 디자인**(특정 상표 모양 흉내 금지). 형상 하나를 병합해 `InstancedMesh` 1개(또는 부위별 소수)로, 옷 색은 `--scene-doll-1~8`에서 행사 id·인덱스 해시로 결정적으로. 정적 배치(P0) — 모형 둘레에 원형 군집, 서로 겹치지 않게
  - **군중 수**(`crowd-scale.ts`): 인형 수 = round(peakP50 ÷ N), N은 전체 합이 품질 단계 상한(high 2,000 · medium 1,000 · low 500 — 04 §9 "낮음 1/4")을 넘지 않게 **목록 전체에서 하나** 고른 깔끔한 수(100·200·500·1,000·2,000·5,000명 …). 행사마다 최소 1개. 범례에 그 N을 쓴다
  - **범례**(`scene-legend.tsx`, DOM 오버레이): "인형 1개 = N명", 등급 깃발 4개(아이콘 + 글자), "움직임은 연출" — 항상 보이고, 기존 `HonestNote`와 한 덩어리로 합친다(중복 문구 제거)
  - 품질 단계 연동(T-431 `quality.ts`): 인형 상한만 바꾼다(그림자 규칙은 그대로). `prefers-reduced-motion`은 이번엔 정적이라 영향 없음
  - 자원 해제: 모형·인형 형상·재료를 언마운트 때 해제(T-431 방식)
