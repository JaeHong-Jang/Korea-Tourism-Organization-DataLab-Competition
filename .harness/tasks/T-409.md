  - **M5-F1 표**: `GET /api/records/events` → 행사명·일자·등급(아이콘 + 글자)·상태(예정·지남·실측 입력됨)·마지막 예보 일시, 정렬(일자·등급·마지막 예보)·상태 필터, 행 선택 → 오른쪽 상세.

  - **M5-F4 실측 입력**: 행사가 지난 행사에만 — 실측 일평균 또는 순간 최대(단위·출처·범위 선택), 입력 검증(양수·단위) → `POST /api/records/actuals` → 채점 표시(예보 구간 안/밖, 계약에 채점 값이 있으면 그대로 — 없으면 구간 포함 여부만 화면 계산하지 말고 "채점은 검증 센터에서" 링크).
  - **M5-F5 공유 링크**: [공유 링크 만들기] → `POST /api/records/shares` → 주소 복사(`/s/{token}`), 새 `/s/:token` 화면은 `GET /api/records/shares/{token}`의 스냅샷을 **읽기 전용 예보서**로(편집·재예보·계획 버튼 없음, "공유된 예보서" 표시).
  - 빈 상태: 저장한 행사가 없으면 펫 + "상담에서 예보를 저장하면 여기에 모여요" + [예보 상담으로].
