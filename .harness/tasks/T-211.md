# T-211: PyMC 계층 베이지안 도전 모델 — 같은 롤링 백테스트로 LightGBM과 비교, "두 모델 합의" 근거(기본 모델은 바꾸지 않음)
- 레인/워커: **L5 워크트리** / gpt-6-astra (forecast `models/`만 — L2는 T-208 중)        - 선행: T-203·T-203b 완료, 의존성 b3c5ff1(`challenger` 그룹 — pymc 6)
- 목표(한 문장): 소표본에 강한 두 번째 모델(유형·시도 부분 풀링, log 일평균)을 사용 모델과 **같은 폴드·같은 라벨**로 백테스트해 비교표를 만들고, 두 모델 80% 구간의 겹침을 `ModelEvidence`("두 모델 합의")로 쓸 수 있게 한다 — 성적과 무관하게 사용 모델(v1)은 그대로다.
- 읽을 것: docs/plan/06 §5(두 번째 모델 — **정본**)·§11(승격 규칙 — 도전 모델은 승격 대상 아님), docs/plan/05 §두 번째 모델, services/forecast/src/crowdcast/models/{train,backtest,baselines,card,report_tables,evaluate,__main__}.py(폴드·라벨 선택·보고서 방식), packages/contracts/schemas/{model-card,backtest-summary,evidence}.schema.json, AGENTS.md §3·§5
- 허용 경로: `services/forecast/src/crowdcast/models/challenger/`(새), `services/forecast/src/crowdcast/models/{backtest,report_tables,card}.py`(비교 섹션 추가만), `services/forecast/tests/models/challenger/`
- 인터페이스:
  - **모델**: log(일평균) ~ 절편 + 유형 효과(부분 풀링) + 시도 효과(부분 풀링) + 보유 공변량(평시 규모·발표치 등 T-203 피처 중 누수 검사 통과분), Student-t 잔차. 샘플링은 재현 가능(시드 고정)하고 짧게(체인·draw 수 설정, 전체 백테스트가 수 분 안) — 필요하면 ADVI 근사로 대체하되 리포트에 밝힌다. 사후 요약(분위수 산출에 필요한 것만)을 `models/<사용모델버전>-challenger/`에 저장.
  - **백테스트**: 사용 모델과 같은 롤링 폴드·같은 학습/평가 라벨로 MdAPE·80% 포함률(n)·환산 판정 재현율 → 백테스트 보고서(`reports/backtest/<run>/`)에 "도전 모델 비교" 표 + 모델 카드에 한 줄. `python -m crowdcast.models challenger --run <runId>`.
  - **합의 근거**: 함수 하나 — 행사 입력 → 도전 모델 80% 구간과 사용 모델 구간의 겹침 비율 → `ModelEvidence`(계약 evidence, "두 모델 합의 N%"). **예보 경로에 연결하지 않는다**(설정 플래그 기본 끔 — 오케스트레이터가 비교표를 보고 켠다). 사전 등록 일괄 예보에는 영향 없음.
- 수용 기준: `pytest -q services/forecast/tests`·ruff(도전 모델 테스트는 작은 합성 자료·짧은 샘플링 — 1분 안), 실제 자료로 비교 백테스트 1회 실행 결과(표·소요 시간)를 리포트에, 사용 모델 예보 바이트 동일 테스트.
