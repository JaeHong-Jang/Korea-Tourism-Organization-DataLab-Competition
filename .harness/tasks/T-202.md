# T-202: 순간 최대 환산(샘플링) + 판정 엔진 + 규모 외 위험 체크리스트 + 근거 조각
- 레인/워커: L2 / gpt-6-astra        - 선행: T-201 완료
- 목표(한 문장): 일평균 예측 분포에서 순간 최대 샘플을 만들고(가정 2개), 법정·자체 규칙으로 4등급을 판정하며, 모든 판정·가정에 근거 조각을 붙인다.
- 읽을 것: docs/plan/06 §4(피크일 계수·동시체류율)·§5(최종 분포 하나에서 모든 숫자)·§6(판정·체크리스트)·§12(근거 조각), docs/plan/09 §5(S05·S06·S07), packages/contracts/schemas/{forecast,judgment,evidence,common}.schema.json
- 허용 경로: `services/forecast/src/crowdcast/rules/{__init__.py,peak.py,judge.py,checklist.py,evidence.py}`, `configs/{peak_profiles.yaml,thresholds.yaml,checklist.yaml}`, `services/forecast/tests/rules/`
- 인터페이스:
  - `peak.sample_peak(daily_quantiles, event, n=4000, seed)` → 순간 최대 샘플(피크일 계수 × 동시체류율, 둘 다 범위 샘플링) + 사용한 가정 id 목록(기준 그래프 id 그대로: `as-peak-day-factor`, `as-concurrency-<유형>` — 불꽃 = `as-concurrency-fireworks`)
  - `judge.judge(samples, event)` → 계약 `judgment`(level·label·ruleIds·reasons·checklist — 법정 사유는 `clauseId` = `law-disaster-act-enf-73-9` 필수, 규칙 id는 `rule-legal-1000`·`rule-legal-hazard`·`rule-internal-*`) + P(≥1000)·P(≥5000). 불·폭죽·가연성·산·수면 → 인원 무관 "수립 대상"(법정). 사유 문구는 템플릿 고정
  - `evidence.rule_evidence(...)`, `evidence.assumption_evidence(...)` → 계약 `evidence`(kind rule·assumption, id는 `ev-` + 입력 해시로 결정적, 필수 필드는 스키마대로 전부 — 해당 없는 칸은 null, `checkResult`는 null)
  - 설정: `configs/*.yaml`(값 옆에 출처·가정 여부 주석)
- 수용 기준(실행 명령):
  - `uv run --package crowdcast-forecast pytest -q services/forecast/tests/rules` 통과: 불꽃 = 인원 무관 대상, p10 ≤ p50 ≤ p90, p50 > 1,000이면 P(≥1000) ≥ 0.5, 같은 seed면 같은 결과, 판정·근거 출력이 계약 스키마 통과
