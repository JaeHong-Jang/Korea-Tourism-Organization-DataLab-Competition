- 인터페이스:
  - **기본 보기 = 실제 3D 지도**: 전환 [3D 지도 | 미니어처 | SVG](2D는 같은 지도의 "위에서 보기" 토글로 합친다 — 기울기 0). 선택은 브라우저에 기억(기존 키 호환), 주소 `?view=`.
  - **지도**: 소스 `korea-z15.pmtiles`, Protomaps light/dark(테마) `lang:"ko"`, **실제 색**(땅 옅은 회색·녹지 초록·물 파랑 — 지금의 누런 흙색 없음), 기울기 55°(최대 70), 하늘·안개(`setSky`), z13부터 **건물 fill-extrusion**(높이 결측 → 층수 추정·기본 10m, 은은한 음영), 주요 도로 폭 강조, 철도·지하철 선.
  - **행사**: 다가오는 행사마다 **3D 기둥**(작은 원 폴리곤 fill-extrusion, 높이 = log(순간 최대 p50) 비례, 색 = 등급 토큰) + 기호 레이어 이름표(행사명 + 등급 아이콘 글자 — MapLibre 충돌 처리로 겹치지 않게, HTML 이름표 수백 개를 쓰지 않는다). 클릭 → 선택 스토어(목록·요약·KPI 동기) + 그 행사로 부드럽게 날아가 확대(z15·기울기 60). 선택 행사 둘레에 예보 규모 원(반투명) + 이미지가 있으면 요약 팝업에 썸네일.
  - **움직임(연출)**: z13 이상에서 화면 안 도로(주요·간선) 선을 모아 경로를 만들고 **버스·승용차**(작은 3D 상자 — three.js custom layer 인스턴싱, 버스는 길고 색 다름)가 도로를 따라 달림, 철도 위 열차. 품질 상한(높음 200·보통 80·낮음 0), 화면 밖·저줌에서는 멈추고 해제, 매 프레임 할당 없음, `prefers-reduced-motion`이면 정지. 모서리에 "건물·도로 = OpenStreetMap · 차량 움직임은 연출 · 인원 규모는 예보값 비례".
  - **성능**: 지도는 MapLibre 타일 LOD에 맡기고, 행사·차량 레이어는 GPU 인스턴싱. 목표: 1440×900에서 전국 보기·도시 확대 모두 부드럽게 — 측정 `--t440`(같은 실행의 미니어처 기준 대비 p95 ≤ 1.0배 — **지금보다 가벼워야 한다**).
  - **미니어처 흰 점**: 사용자 화면(전국 판 확대)에 판·바다 위로 흰 점이 흩뿌려짐 — 원인(후처리 아님 — 오케스트레이터가 A/B로 배제)을 레이어별로 찾아 없앤다(리포트에 원인 한 줄).
