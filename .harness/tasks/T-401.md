- 인터페이스:
  - `package.json` 이름 `@crowdcast/web`, 스크립트 `dev`(vite), `build`(tsc + vite build), `test`(vitest run), `lint`(biome), `e2e`(playwright). 레포 루트에서 `npm -w apps/web run dev -- --port 5173 --strictPort`로 뜬다(dev.mjs 등록 명령)
  - 스타일: Tailwind CSS v4(`@tailwindcss/vite`), `@crowdcast/contracts/design-tokens.css`를 불러와 토큰만 쓴다(색 하드코딩 0). shadcn/ui 부품은 CLI로 넣되 모서리·높이·포커스·그림자를 토큰으로 다시 정의
  - 글꼴: `pretendard` 패키지의 웹폰트를 `public/fonts/`에 self-host, `font-display: swap`
  - 라우팅(React Router): `/` 미니 대한민국, `/consult` 예보 상담, `/f/:forecastId` 예보서, `/f/:forecastId/plan` 계획 초안, `/my` 내 행사, `/validation` 검증, `/insights` 인사이트, `/ops` 운영, `/dev/*` 견본(개발용, 내비에 안 보임)
  - 헤더(G-F1·G-F2): 로고 "인파예보" + 메뉴 6개(미니 대한민국·예보 상담·내 행사·검증·인사이트·운영), 현재 메뉴 표시(굵기 + 밑줄), 키보드 이동, 오른쪽에 날씨 칩(P0: "서울 · 밤 19:40"처럼 지역·해 상태·시각만) + 테마 선택(자동·낮·밤)
  - 테마 엔진(`src/lib/theme/`): `suncalc`로 해 고도 → 낮(h > 6°)·노을(−6° < h ≤ 6°)·밤(h ≤ −6°), `<html data-theme="day|night" data-sky="day|dusk|night">`, 사용자 선택은 localStorage에 기억(try/catch), 1분마다 재계산, `?theme=night&at=2026-10-18T19:00+09:00` 쿼리로 강제(스크린샷·데모용)
  - 화면 자리: 각 페이지는 11번 명세의 **기능 블록(M?-F?)마다 제목 + 한 줄 설명이 있는 빈 패널**을 04 §4 레이아웃대로 배치한다(S1은 전체 화면 장면 자리 + 떠 있는 필터·목록·타임라인 패널, S2는 대화 40% / 예보팀 작업판 + 예보서 미리보기 60%, S3는 문서 880px + 근거 서랍 360px). 빈 패널에도 가짜 숫자를 넣지 않는다
  - 공용: `src/lib/selection-store.ts`(Zustand — 선택한 행사 id·필터, 다른 웹 레인은 export된 동작만 쓴다), `src/lib/api-client.ts`(게이트웨이 `/api` 호출 + 계약 타입 `@crowdcast/contracts/types`), Vite dev 서버에서 `/api`를 `http://127.0.0.1:8787`로 프록시
  - 경계 파일: `apps/web/public/geo/sigungu.topo.json`은 git에 넣지 않고 `data/external/boundaries/sigungu.topo.json`을 가리키는 심볼릭 링크로 둔다(없으면 만들고 `.gitignore`는 건드리지 않는다 — 오케스트레이터가 추가)
