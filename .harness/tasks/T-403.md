- 인터페이스:
  - **보기 전환**: S1 장면 모서리에 [3D | 2D 지도] 전환(브라우저에 기억, try/catch). WebGL이 없으면 지금처럼 SVG(2D 지도도 WebGL이 필요하다 — 전환 버튼에 이유 표시). 주소 `?view=2d`로도 연다.
  - **지도**: `pmtiles` 프로토콜 등록 → 소스 `pmtiles:///tiles/korea-z13.pmtiles`(절대 URL로 변환), `@protomaps/basemaps` 레이어 `lang:"ko"`, 테마 낮·밤 → light·dark flavor, glyphs `/tiles/fonts/{fontstack}/{range}.pbf`, sprite `/tiles/sprites/v4/{light|dark}`, `localIdeographFontFamily`로 한글 라벨을 로컬 글꼴(Pretendard) 렌더 — **외부 네트워크 요청 0**(e2e로 확인). 첫 화면 = 남한 전체가 떠 있는 패널을 뺀 영역에 들어오게(패널 경계 캐시 재사용). maxZoom 13(넘으면 과확대 표시).
  - **행사 점**: 필터 반영 행사(`/api/festivals`)를 GeoJSON 원 레이어로 — 색 = 등급 토큰, 반지름 = 예보 규모(구간), 등급은 색만으로 말하지 않게 선택 시 팝업/요약에 아이콘 + 글자. 클릭 → 선택 스토어(목록·요약·KPI 동기), 목록 선택 → 지도가 그 점으로 이동, Esc → 해제. 겹친 점은 클러스터(개수 표시).
  - 접근성: 지도 컨테이너 `role="region"` + 이름, 키보드 확대·이동(MapLibre 기본) + 행사 선택은 목록으로 가능하다는 안내.
