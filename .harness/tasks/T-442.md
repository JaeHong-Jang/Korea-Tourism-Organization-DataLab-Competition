- 인터페이스:
  - **떠다니는 고래 봇**: 모든 화면 오른쪽 아래에 작은 3D 고래(저폴리 — 펫 고래와 같은 실루엣, 캔버스 하나·낮은 DPR·화면 밖·탭 숨김이면 렌더 멈춤, `prefers-reduced-motion`이면 정지 그림)가 천천히 떠다님, 누르면 **대화 패널**(오른쪽 서랍 — 넓은 화면은 옆, 390폭은 전체 시트)이 열림. 예보팀이 일하는 중이면 봇 위에 작은 상태(작업 중·발행됨).
  - **대화 패널**: 대화·되묻기·후속 칩·what-if 비교를 여기서(기존 컴포넌트 재사용). **되묻기 답은 입력칸에서** — 선택지는 입력칸 위 칩, 자유 답은 입력칸에 그대로 쓰고 [보내기](질문 밑의 따로 뜨는 "직접 입력" 칸 제거), 날짜·시각 되묻기는 입력칸 위 작은 선택기.
  - **행사 고르기**: 패널 첫 화면에 "다가오는 행사에서 고르기" 검색(이름·지역·날짜 — `/api/festivals` 목록에서 두 글자부터 제안) → 고르면 메시지 `{text: "<행사명> 예보해 줘", eventId}` → 입력 없이 예보. S1 목록 카드·요약 패널의 [예보 상담에서 자세히 보기] → **[이 행사 예보 받기]**(패널을 열고 같은 방식으로 보냄).
  - **방문객 추천**: `recommend` 이벤트 → 추천 카드 목록(대표 이미지 있으면 썸네일·없으면 유형 그림, 행사명·날짜·장소·등급(아이콘 + 글자)·순간 최대 구간·`reason`, [지도에서 보기] → S1에서 그 행사 선택, [이 행사 예보 받기]는 주최자용 버튼으로 작게), 빈 목록이면 `note`와 조건 바꾸기 칩.
  - **예보 상담 화면(S2) = 작업판 + 예보서 미리보기 + 행사 카드만**: 대화 칸을 없애고, 같은 세션 상태(전역 스토어)를 보여 준다. 화면에 들어오면 대화 패널을 옆에 열어 둔다(닫을 수 있음). 비어 있으면 "고래를 눌러 행사를 고르거나 설명해 보세요" + [행사 고르기].
