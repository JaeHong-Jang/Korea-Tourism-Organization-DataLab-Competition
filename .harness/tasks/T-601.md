# T-601: 근거 그래프 서비스 골격 + 온톨로지 TTL v1 + 기준 그래프 + 세션 적재 최소판
- 레인/워커: L6 / gpt-6-astra        - 선행: R-01 통과
- 목표(한 문장): 온톨로지(09 §3~4)와 기준 그래프를 TTL로 만들고, 계약 JSON을 계약의 JSON-LD 규칙으로 RDF로 바꿔 세션 named graph에 적재(참조가 끊기면 거부)하고 revision을 올리는 최소 서비스를 만든다.
- 읽을 것: docs/plan/09 전체(특히 §1 검증 범위·§2 IRI 규칙·§3 클래스·§4 속성·§6 예시·§10 API), packages/contracts/jsonld/(context.jsonld·types.json·expected/), packages/contracts/check/jsonld_check.py(변환 기준 구현), packages/contracts/openapi/knowledge.yaml, packages/contracts/fixtures/·fixtures-integrity/, AGENTS.md §3·§5
- 허용 경로: `services/knowledge/ontology/crowdcast.ttl`, `services/knowledge/ontology/master/` (`datasets.ttl`·`laws.ttl`·`rules.ttl`·`assumptions.ttl`·`agents.ttl`), `services/knowledge/src/knowledge/{api,store,convert}/`, `services/knowledge/tests/`
- 인터페이스:
  - `uv run --package crowdcast-knowledge uvicorn knowledge.api.app:app --port 8020`, `GET /health` → `{"status":"ok","version":"0.1.0"}`
  - IRI: 인스턴스 = `http://crowdcast.local/id/<계약 id>`(평면). 에이전트 = `id:agent-<agentId>`, 시군구 = `id:<코드 5자리>`. 세션 named graph IRI = 세션 IRI(`id:s-…`)
  - `convert.json_to_graph(obj, schema) -> rdflib.Graph`: `jsonld/types.json`의 경로 규칙으로 `@type`을 붙이고(`@include` 포함) `jsonld/context.jsonld`로 **pyld** `to_rdf` → rdflib. 계약 파일은 복사하지 말고 `packages/contracts/jsonld/`에서 읽는다
  - `convert.integrity_problems(obj, schema, known_ids) -> list[str]`: 문서 안 참조(observationIds·evidenceIds·assumptionIds·placeholders.quantityId·ruleId·clauseId·datasetId)가 같은 문서·세션 그래프·기준 그래프에 없으면 문제로 돌려준다(`packages/contracts/scripts/check.mjs`의 `refProblems`와 같은 판정 + 기준 그래프 조회)
  - `POST /v1/sessions/{id}/facts` body `{"schema": "forecast"|"claim"|"evidence"|"similar-event"|"region-baseline", "items": [...]}` → 끊긴 참조가 있으면 **422 + `gate-report`**(gate `integrity`, 위반마다 노드·메시지)로 거부하고 아무것도 쓰지 않는다. 통과하면 세션 named graph에 적재, `{"revision": n}`(쓰기마다 1 증가, 세션 잠금으로 순서 보장)
  - `GET /v1/master/version` → `{"masterVersion": n}`
  - 저장소: pyoxigraph `Store`(경로 `data/app/knowledge/`, 테스트는 메모리)
  - 기준 그래프(`master/*.ttl`, 모두 `id:` 평면 IRI): 데이터셋 `ds-…` — 15101972(`ds-kto-visitors-15101972`)·15128555·15101578·15012690·15084084·15059468 API, 데이터랩 메뉴(문화관광축제 현황·행사/축제 DIY·빅데이터 지역별 방문자수·내비 검색건수·관광지 검색순위·지역별 관광현황), 문체부 지역축제 개최계획, 행안부 매뉴얼 / 법령 `law-disaster-act-enf-73-9` / 규칙 `rule-legal-1000`·`rule-legal-hazard`·`rule-internal-10pct`·`rule-internal-50pct`·`rule-internal-5000` / 가정 `as-peak-day-factor`·유형별 `as-concurrency-*`(불꽃 = `as-concurrency-fireworks`) / 모델 실행 `mr-v0-1-0` / 에이전트 13명 `agent-<agentId>` a `cc:TeamAgent`. 기준 그래프 버전 번호(`cc:masterVersion`) 포함
