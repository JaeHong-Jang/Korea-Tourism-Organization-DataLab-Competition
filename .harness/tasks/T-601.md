# T-601: 근거 그래프 서비스 골격 + 온톨로지 TTL v1 + 기준 그래프 + 세션 적재 최소판
- 레인/워커: L6 / gpt-6-astra        - 선행: R-01 통과
- 목표(한 문장): 온톨로지(09 §3~4)와 기준 그래프를 TTL로 만들고, JSON-LD 조각을 세션 named graph에 적재해 revision을 올리는 최소 서비스를 만든다.
- 읽을 것: docs/plan/09 전체(특히 §1 검증 범위·§3 클래스·§4 속성·§6 예시·§10 API), packages/contracts/jsonld/context.jsonld, packages/contracts/openapi/knowledge.yaml, packages/contracts/fixtures/, AGENTS.md §3·§5
- 허용 경로: `services/knowledge/ontology/crowdcast.ttl`, `services/knowledge/ontology/master/` (`datasets.ttl`·`laws.ttl`·`rules.ttl`·`assumptions.ttl`), `services/knowledge/src/knowledge/{api,store,convert}/`, `services/knowledge/tests/`
- 인터페이스:
  - `uv run --package crowdcast-knowledge uvicorn knowledge.api.app:app --port 8020`, `GET /health` → `{"status":"ok","version":"0.1.0"}`
  - `POST /v1/sessions/{id}/facts` body `{"@graph":[...]}` (계약 JSON-LD 컨텍스트 사용) → 세션 named graph `http://crowdcast.local/id/session/{id}`에 적재, `{"revision": n}` 반환(쓰기마다 1 증가, 세션 잠금으로 순서 보장)
  - 저장소: pyoxigraph `Store`(경로 `data/app/knowledge/`, 테스트는 메모리)
  - 기준 그래프(`master/*.ttl`): 데이터셋 — 15101972·15128555·15101578·15012690·15084084·15059468 API, 데이터랩 메뉴(문화관광축제 현황·행사/축제 DIY·빅데이터 지역별 방문자수·내비 검색건수·관광지 검색순위·지역별 관광현황), 문체부 지역축제 개최계획, 행안부 매뉴얼 / 법령 `law:disaster-act-enf-73-9` / 규칙 `rule:legal-1000`·`rule:legal-hazard`·`rule:internal-10pct`·`rule:internal-50pct`·`rule:internal-5000` / 가정 `as:peak-day-factor`·유형별 `as:concurrency-*`. 기준 그래프 버전 번호 포함
  - `convert.json_to_graph(obj)`: 계약 JSON(forecast·evidence·claim)을 컨텍스트로 RDF로 바꾼다(`@type`은 종류 필드에서 결정)
- 수용 기준(실행 명령):

  - `node scripts/dev.mjs --check`에 `✓ knowledge`
