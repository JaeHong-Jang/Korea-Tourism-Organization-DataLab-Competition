# T-100: 문체부 지역축제 개최계획 xlsx 파서 + DIY 대상 목록
- 레인/워커: L1 / gpt-6-astra        - 선행: R-01(계약 검토) 통과
- 목표(한 문장): 2017~2026년 문체부 지역축제 개최계획 xlsx를 하나의 정규화된 행사 표로 만들고, 사람(H3)이 데이터랩 DIY로 라벨을 만들 대상 60건 이상을 우선순위대로 뽑는다.
- 읽을 것: docs/plan/06 §1·§2(골드B·DIY)·§5(Polars·DuckDB·Pandera), docs/plan/05 §3, AGENTS.md §3·§5, packages/contracts/schemas/common.schema.json(eventType·sigunguCode)
- 입력(읽기 전용): `data/20*_festival/**/*.xlsx` (연도별 파일, 2017~2021은 시도별 시트 18개, 2022~2026은 시트 2~3개. 머리글 행 위치·병합 셀·열 이름이 연도마다 다르다). 파일을 옮기거나 고치지 않는다.
- 허용 경로: `services/forecast/src/crowdcast/data/__init__.py`, `services/forecast/src/crowdcast/data/mcst_festivals.py`, `services/forecast/src/crowdcast/data/diy_targets.py`, `services/forecast/tests/data/` (테스트·작은 합성 xlsx 픽스처)
- 실행 산출물(git 제외): `data/processed/mcst_festivals.parquet`, `data/processed/mcst_festivals_qc.md`, `data/processed/diy_targets.csv`
- 인터페이스:
  - `uv run --package crowdcast-forecast python -m crowdcast.data.mcst_festivals` → parquet + QC 리포트. 열: `year, sido, sigungu_name, festival_name, type_raw, type(eventType enum 매핑, 모르면 "기타"), start_date, end_date, days, venue, host, budget_krw(원 정수, 없으면 null), visitors_announced(정수, 없으면 null), visitors_announced_meaning(열 이름 원문: 예 "전년도 방문객"), source_file, source_sheet, source_row`
  - `uv run --package crowdcast-forecast python -m crowdcast.data.diy_targets` → `diy_targets.csv`: 2023~2025년 행사 중 `visitors_announced`가 500~20,000인 중소 행사 우선, 유형·시도가 고르게 섞이게 60건 이상. 열: `priority, festival_name, year, sido, sigungu_name, venue, start_date, end_date, days, visitors_announced, why(뽑은 이유 한 줄)`
  - Pandera 스키마로 두 표를 검증한다(필수 열 타입·날짜 순서·days ≥ 1).
- 수용 기준(실행 명령):
  - `uv run --package crowdcast-forecast pytest -q services/forecast/tests/data` 통과(합성 xlsx 픽스처로 머리글 탐지·병합 셀·날짜 형식 여러 가지를 검증, 네트워크 없음)
  - 실제 데이터로 두 명령을 실행해, QC 리포트에 **연도별 행 수**(각 연도 ≥ 300), 필수 열 결측률, 매핑 못 한 유형 목록이 나오고, `diy_targets.csv`가 60행 이상
- 범위 밖: 시군구 코드 매핑(T-102), API 호출, 라벨 계산, 다른 레인 파일
- 외부 호출: 없음(패키지 설치를 위한 네트워크만 허용 — `uv sync`)
- 코드 규칙: AGENTS.md §5 (파일·문단마다 한국어 한 줄 주석, 기능별 파일 분리, 도메인 이름)
- 리포트: AGENTS.md §4 형식
