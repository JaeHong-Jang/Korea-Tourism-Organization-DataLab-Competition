- 인터페이스:
  - **의도 분류**: 키워드 규칙 먼저(요일·날짜 표현 → 날짜, "밤/낮/저녁" → 시간대, "유료/무료/입장료" → 요금, "공연이면/먹거리면" → 유형, "비 오면/눈 오면" → 날씨, "비슷한 행사/다른 행사" → 유사), 규칙으로 못 정하면 LLM 한 번(상한 안). 바꿀 값이 모호하면 되묻기(버튼 선택지).
  - **날짜·시간대·요금·유형** → 세션의 발행 예보 행사 입력에 변경을 적용해 `/v1/whatif` → 게이트 A → 보고팀 → 게이트 B → **새 forecastId로 발행**(`new` 모드). 보고팀은 첫 설명 문장에 "○○으로 바꾼 조건의 예보"를 **숫자 없이** 밝힌다(비교 숫자는 화면이 두 카드로 보여 준다). `done`에 원래 예보 id를 함께 싣는다(계약에 필드가 없으면 기존 필드만 — 세션 상태로 화면이 안다, 새 필드는 CONTRACT-CHANGE 요청으로).
  - **날씨("비 오면?")** → 새 예보 없이 `followup`: 우천 체크리스트 규칙·날씨 보정 가정(`as-weather-adjustment` — 과거 강수일 자료 없으면 보정 없음)을 근거로 한 발행 문장. **유사("비슷한 행사는?")** → 발행 스냅샷의 유사 행사 근거로 답(새 숫자 없음).
  - 발행 예보가 없는 세션에서 what-if를 물으면 "먼저 예보를 만들어요" 안내.
