- 인터페이스:
  - **호환성 먼저**(`compat.py` + 테스트): LightGBM 4.6 quantile(α 0.1·0.5·0.9)이 합성 자료에서 학습·저장·불러오기 되고, `monotone_constraints`를 주면 거부하는 우리 쪽 가드(06 §5 — 4.6은 중단된다). 이 테스트가 통과해야 나머지를 돌린다
  - **피처**(06 §3): 행사(유형·기간·주말·공휴일 일수·시간대·무료·주최 유형·회차·log 예산(결측 허용)·위험 요소), 이력(전회차 라벨 — `available_at ≤ as_of`인 것만), 개최지(`region_daily`에서 as_of 이전 8주 일평균·외지인 비중·주말 배수 — `available_at ≤ as_of`인 날만), 달력(월·연휴 길이). `as_of = 시작일 − 14`. 피처 값마다 `available_at`을 함께 두고 **`availability.py`가 위반 1건이라도 있으면 예외로 멈춘다**(06 §8 features 게이트). 없는 자료(TMAP 등)는 넣지 않는다
  - **학습 표본**: `usable_for_training & is_primary & !is_golden`. 실버 가중치는 `configs/model.yaml`(기본 0.5, 골드 1.0). 코로나(2020·2021)는 기본 제외(설정), 뺀 건수 기록
  - **모델**: 대상 log1p(일평균), num_leaves ≤ 15, min_data_in_leaf ≥ 10(설정), 시드 고정. 구간 보정은 MAPIE CQR(평가 연도 Y마다 **학습 ≤ Y−2, 보정 Y−1, 평가 Y**). p10 ≤ p50 ≤ p90 정렬(교차 제거)
  - **분포·순간 최대·판정**: 보정된 세 분위수 → `rules/peak.py`의 `sample_peak`(T-202) → `rules/judge.py`. `distribution.py`는 두 모듈을 잇는 얇은 층만(샘플 수·시드 고정). 단위테스트: 순서, `p50 > 1000`이면 P(≥1000) ≥ 50%
  - **기준선**(06 §5): B0 유형 중앙값(학습 구간만), B1 전회차 실측(공개 시점 규칙), B2 주최측 **사전 예상** — `events`에 단위가 일평균과 같은 사전 예상이 있는 쌍만(없으면 `comparablePairs = 0`으로 정직하게)
  - **백테스트**(`python -m crowdcast.models backtest`): 평가 연도는 `configs/model.yaml`(기본 2024·2025, 학습 연도가 모자라면 그 해는 건너뛰고 사유 기록). 지표 = 계약 `backtest-summary.metrics`(MdAPE·80% 포함률·포함 표본 수·환산 판정 재현율·정밀도 — 실측 일평균도 같은 환산으로 등급을 만들어 비교·기준선 대비 %p·비교 가능 쌍). 등급별(골드/실버)·규모대별(일평균 <1,000 / 1,000~5,000 / >5,000)·연도별 표를 `backtest.md`에. `golden` = 골든 행사 재현(없으면 빈 배열 + 사유)
  - **설명**: SHAP 상위 5개 → 계약 `factor`(evidenceIds는 빈 배열 — T-204가 근거 id를 붙인다). **OOD**: 유형×규모대 학습 표본 < 5 또는 피처가 학습 범위 밖
  - **모델 카드**: 계약 `model-card`(id = `mr-` + modelVersion, trainRange, features, evalYears, backtestRunId, notes에 라벨 파일 SHA-256·실버 가중치·코로나 제외 여부·"목표 포함률 80%(보장 아님)")
  - **결정성**: 같은 입력·시드 → `backtest.json` 지표 같음(테스트)
- 수용 기준(실행 명령):
  - `uv run --package crowdcast-forecast pytest -q services/forecast/tests/features services/forecast/tests/models` 통과: 호환성, **누수 테스트**(as_of 뒤에 공개된 값을 넣은 합성 행 → 멈춤), 공개 시점 경계(`available_at == as_of`는 허용), CQR 분할(학습 ≤ Y−2·보정 Y−1 — 평가 연도 행이 학습에 없음), 기준선 B2 단위 불일치 제외, 분포 순서·확률 일관성, 결정성
  - 실제 실행: `python -m crowdcast.models backtest` → `backtest.json`·`model_card.json`이 계약 스키마 통과(`packages/contracts/check/python_check.py`의 validate 사용 — 방법을 리포트에), 전체 실행 10분 이내(노트북)
  - 리포트에 **숫자 그대로**: 연도별 N·MdAPE·포함률(표본 수)·구간 폭 중앙값·기준선 대비, 판정 재현율·정밀도, 건너뛴 연도와 사유, 산출물 SHA-256. 성적이 나빠도 고치려고 평가 자료를 보지 않는다(튜닝은 학습·보정 구간 안에서만)
