  - **노드**: TBox 클래스(`kind:"class"` — cc: 클래스와 쓰는 PROV 클래스, 라벨 = 한국어 rdfs:label), 규칙(`rule` — 법정/자체를 note에), 조항(`clause` — url = 법령 원문), 데이터셋(`dataset` — url = 데이터랩 메뉴/포털), 가정(`assumption` — 값·범위를 note), 모델 실행(`model` — 버전·검증 상태), 파이프라인 단계·파일(`stage`·`file` — 계보), 에이전트(`agent`). 라벨은 master-labels 한국어 이름 우선.
  - **간선**: rdf:type(개체 → 클래스, 라벨 "종류"), TBox 관계(rdfs:domain/range로 클래스 사이 "관계 이름"), 기준 그래프의 실제 관계(규칙 → 조항 `cc:basedOn` 등, 모델 → 데이터셋, 단계 → 파일 `prov:used`·`prov:wasGeneratedBy`, 파일 → 데이터셋 `prov:wasDerivedFrom`) — `predicate`는 CURIE, `label`은 한국어.
  - 크기: 노드 ≤ 600(파일은 경로 묶음으로 합쳐도 됨), 결정적 순서(같은 masterVersion = 같은 응답), masterVersion·생성 시각 포함, 계약 검증 뒤 응답. 세션 그래프는 넣지 않는다.
